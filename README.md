# FictionBook Editor Next

**FictionBook Editor Next (FBE Next)** — бесплатный редактор электронных книг формата **FictionBook 2 (`.fb2`)** для Windows. Проект продолжает развитие классического FictionBook Editor: сохраняет привычное визуальное редактирование, работу со структурой книги и JavaScript-скриптами, дополняя их современными инструментами и повышенной надёжностью.

**Актуальный стабильный выпуск: [3.0.10](https://github.com/sklart/fictionbook-editor-next/releases/tag/v3.0.10) (23 октября 2026 года).**

**Установщик** позволяет выбрать обычную установку для текущего пользователя (*Current User*, без обязательного повышения прав), установку для всех пользователей (*All Users*, с правами администратора) или создание переносимой копии (*Portable*). Компоненты интеграции с Windows выбираются отдельно.

**Portable** хранит изменяемые настройки и данные в собственном каталоге `Data`, в том числе конфигурацию, скрипты, словари, темы, историю файлов и диагностику. Папку следует переносить вместе с `Data`. Простая распаковка ZIP не назначает FBE Next приложением по умолчанию и не устанавливает расширения Проводника.

Проверка обновлений доступна в окне **«О программе»**. Можно использовать стабильный канал или канал предварительных версий Beta/RC; portable-копия не должна превращаться в установленную версию при обновлении.

**Важно:** все основные опубликованные файлы 3.0.10 имеют архитектуру **Win32 (x86)**. Это обозначение разрядности приложения, а не требование 32-разрядной Windows: приложение рассчитано и на 64-разрядные системы. Подробнее о Windows 7 — [ниже](#совместимость-с-windows).

## Основные возможности

### Редактирование книги

FBE Next предназначен для ручной подготовки, исправления и структурирования FictionBook-книг:

- **«Тело»** — привычное визуальное редактирование текста без необходимости вручную писать XML.
- **«Описание»** — метаданные книги: название, авторы, язык, жанры, серия, аннотация и другие сведения.
- **«Код»** — прямое редактирование исходного XML для точной разметки и нестандартных случаев.
- Работа с главами и вложенными разделами, заголовками, эпиграфами, цитатами, стихами, примечаниями, комментариями, ссылками и иллюстрациями.
- Визуальное создание и редактирование **таблиц FB2**, включая объединённые ячейки (`rowspan`, `colspan`) и преобразование заголовочных/обычных ячеек.
- Вставка изображений разных форматов с преобразованием для FB2 (включая WebP, JPEG 2000, AVIF, HEIC/HEIF, BMP, GIF, TIFF, JPEG и PNG).
- Сохранение позиции и выделения при переходе между «Телом» и «Кодом» в поддерживаемых сценариях.
- **Ctrl+Click** по внутренним ссылкам для перехода внутри книги; наведение на ссылку-примечание показывает быстрый предпросмотр.
- Работа с файлами `.fbd` (документами описания FictionBook).

### Поиск и замена

Поиск переработан для работы с большими книгами, повторяющимися фрагментами и регулярными выражениями:

- поиск по документу, выделению и доступным областям книги;
- команда **«Найти всё»** с панелью результатов, контекстом и переходом к совпадению;
- подсветка всех найденных фрагментов без изменения FB2;
- список потенциальных совпадений массовой замены с подтверждением выполнения; сравнение текста «до/после» и исключение отдельных совпадений не предусмотрены;
- библиотека встроенных шаблонов и сохранение собственных;
- встроенная справка по регулярным выражениям.

В визуальном редакторе используется **PCRE2**, в режиме «Код» — механизм поиска **Scintilla**. Возможности и синтаксис этих режимов могут различаться; справка учитывает это.

### Редактор XML

Режим «Код» основан на Scintilla и предназначен для точной работы с разметкой FictionBook:

- подсветка XML с готовыми и внешними цветовыми схемами;
- автодополнение допустимых элементов, атрибутов, закрывающих тегов и ссылок на существующие идентификаторы;
- обнаружение XML-ошибок возле проблемной строки;
- поиск парных тегов и навигация по ним;
- настраиваемое отображение невидимых символов (`NBSP`, `SHY` и другие);
- настройки текстового курсора (толщина, цвет и мигание);
- оптимизации повторного открытия представления «Код» и работы с большими документами.

### Скрипты и панели инструментов

FBE Next сохраняет поддержку штатных и пользовательских JavaScript-скриптов классического редактора. Доступны большой комплект скриптов для обработки текста и структуры книги, команды их запуска и настройки собственных сочетаний клавиш.

В версиях 3.0.8–3.0.9 добавлены и доработаны:

- **отдельный режим дерева скриптов** с поиском и избранным;
- создание, переименование, скрытие и перестановка пользовательских панелей инструментов;
- индивидуальная настройка состава кнопок и разделителей каждой панели;
- привязка панелей к скриптам, сохраняемая при их переименовании или переносе внутри каталога;
- обновление списка скриптов без перезапуска приложения;
- **карточки скриптов** с назначением, авторами, параметрами, зависимостями и ограничениями;
- расширенные сообщения об ошибках загрузки и выполнения скриптов;
- дополнительные методы `window.external` для безопасной проверки и применения изменений исходного XML с поддержкой штатного Undo/Redo.

В 3.0.10 API скриптов расширен до **1.5.0 (104 метода)**: добавлены безопасное сохранение, независимые копии книги и сериализация. Описание методов и примеры — в [документации API](docs/scripting-api.md).

### Проверка качества FB2

Кроме штатного **FictionBook Validator (FBV)**, проверяющего структуру и схему документа, FBE Next предлагает отдельный **анализ качества книги**. Он помогает находить не только формальные XML-ошибки, но и практические проблемы подготовки электронного издания.

Проверяются, в частности, внутренние ссылки, примечания, изображения и бинарные вложения, структура разделов и подозрительные метаданные. Результаты разделяются на ошибки, предупреждения и сведения; доступны рекомендации, переход к соответствующему месту XML (когда его можно определить) и сохранение отчёта в TXT или HTML. Проверку можно отменить.

<img src="https://github.com/user-attachments/assets/1a7f7fdc-fd43-4cb0-a575-654e1b7b3a42" alt="Окно проверки качества FB2" width="780">

*Отдельное окно проверки качества FB2.*

Проверка качества анализирует документ и не исправляет его автоматически. Она **дополняет, а не заменяет** проверку корректности FB2 валидатором.

### Импорт, экспорт и архивы

| Операция | Возможности |
| --- | --- |
| **Открытие и сохранение** | FB2, документы описания FBD; работа с выбранным FB2 внутри ZIP-архива. |
| **Импорт** | EPUB → FB2, включая распространённые EPUB 2 и EPUB 3; настройки импорта и диагностика ошибок. |
| **Экспорт** | FB2 → HTML, DOCX, EPUB 2 / EPUB 3. |
| **Пакетное преобразование** | Отдельные batch-утилиты для импорта EPUB и экспорта DOCX/EPUB. |

**Экспорт HTML** предлагает выбор оформления страницы, шрифта, ширины текста, полей, оглавления, примечаний, метаданных, обложки и режима размещения изображений. Поддерживаются автономный HTML с включёнными ресурсами и другие предусмотренные экспортёром HTML-режимы.

Можно разделить HTML-книгу на страницы по разделам, если выбран **встроенный XSL-шаблон** и совместимый HTML-формат. Для MHT, однофайлового автономного HTML и пользовательского шаблона эта возможность не заявляется.

<img src="https://github.com/user-attachments/assets/6aec70a8-b6c5-46e5-8e97-d70edbb8b0ac" alt="Настройки экспорта HTML" width="760">

**Книги в ZIP:** если в архиве несколько FB2, редактор предлагает выбрать нужную книгу. Изменения сохраняются обратно в ZIP с защитой от частичной перезаписи. Поддержка архивного редактирования в этом режиме относится к **ZIP**, а не ко всем форматам архивов.

<img src="https://github.com/user-attachments/assets/1dead6aa-b15e-4e9a-b706-57fa0fa75e9a" alt="Выбор книги из ZIP-архива" width="580">

При ошибке или отмене экспорта HTML, DOCX или EPUB существующий результат защищён от обычной частичной перезаписи. Импорт EPUB проверяет готовность обязательных ресурсов и сообщает о проблемах обязательных глав вместо молчаливого импорта неполной книги.

### Оформление и локализация

FBE Next предлагает **светлую и тёмную темы приложения**, оформление редактора, фоновые изображения под бумагу, собственные цвета текста и фона и предварительный просмотр выбранных параметров. Для XML доступны наборы цветовых схем, включая внешние палитры.

<img src="https://github.com/user-attachments/assets/e4168fc8-6f40-40ca-80f4-b6fb94b56286" alt="Настройка оформления визуального редактора" width="730">

*Оформление режима «Тело»: цвета, фон и предпросмотр.*

Интерфейс переведён на **12 языков**: русский, украинский, английский, немецкий, французский, испанский, итальянский, нидерландский, польский, португальский, чешский и болгарский. Язык можно переключать во время работы программы; для некоторых второстепенных строк используются резервные переводы. Словари орфографии выбираются отдельно от языка интерфейса.

В комплект входят словари для проверки орфографии через Hunspell. Улучшена работа с мягкими переносами, сложными словоформами и предложениями исправлений; для русского языка предусмотрен ограниченный необязательный контроль отдельных ошибок с буквой «ё».

### Сохранность и диагностика

Редактор использует безопасную схему записи документов с подготовкой временного файла и заменой результата. Для существующих книг можно включать или отключать создание предыдущей версии как `.bak` (по умолчанию включено); это не отменяет безопасный способ записи.

В последних выпусках дополнительно улучшены:

- проверки таблиц и бинарных объектов перед сохранением;
- корректное сохранение неразрывных пробелов независимо от их визуального обозначения;
- восстановление после аварийного завершения;
- Undo/Redo для вставки текста, структурных операций, перетаскивания и импорта иллюстраций;
- сохранение истории отмены при поддерживаемых XML-операциях скриптов;
- поведение «Сохранить как», списка последних документов и сохранения в архив.

Окно **«Справка → Диагностика FBE Next…»** показывает сеансы, сведения об ошибках и доступные отчёты. Можно просмотреть будущий состав ZIP-пакета, исключить необязательные компоненты, сохранить проверенный снимок и очистить старые журналы. Подготовка выполняется без блокирования основного окна; пакет **не отправляется по сети автоматически**.

*Диагностические сеансы и подготовка пакета для сообщения об ошибке.*

Подробная инструкция: [Как сообщить об ошибке](docs/reporting-issues.md). При работе с конфиденциальными книгами проверяйте состав отчёта перед передачей разработчикам; исходный текст книги не должен автоматически включаться в стандартный пакет.

### Интеграция с Windows

Установщик позволяет **независимо** включить три функции:

1. назначить FBE Next приложением для открытия `.fb2`;
2. добавить в контекстное меню Проводника команду **«Проверить FB2 на ошибки»**;
3. добавить свойства FB2 (автор, название, язык, серия и др.) и миниатюры обложек в Проводнике.

Это позволяет пользоваться другой читалкой как программой по умолчанию, но при этом сохранить дополнительные возможности FBE Next в Проводнике. Миниатюры сохраняют пропорции обложек и учитывают прозрачность PNG; повреждённая обложка не должна приводить к падению Проводника.

Подробные изображения интеграции, проверок и импорта/экспорта представлены в [исторической галерее ниже](#скриншоты-предыдущих-выпусков).

## Совместимость с Windows

FBE Next — **32-разрядное приложение Win32** для Windows. В проекте поддерживается совместимость с Windows 7 SP1 на уровне целевых API и сборки; современная функциональность DPI и оформление применяются с учётом возможностей установленной системы.

| Система | Статус |
| --- | --- |
| **Windows 11 / Windows 10** | Основная среда современного использования и проверок. |
| **Windows 8.1** | Учитывается существующей политикой совместимости Win32. |
| **Windows 7 SP1** | Совместимость сохраняется как целевая, но **полные ручные испытания официальной 3.0.10 на реальной Windows 7 не подтверждены**. Требуются системные обновления и соответствующие runtime-компоненты. |
| **Windows Vista / Windows XP** | Не поддерживаются стандартной сборкой Next. |

В 3.0.10 опубликованы **единые** `win32`-пакеты без отдельного архива с `win7` в имени. Старые релизы содержали как специальные сборки, так и совместимые дубликаты под отдельными именами; ориентируйтесь на фактические файлы [конкретного выпуска](https://github.com/sklart/fictionbook-editor-next/releases/tag/v3.0.10), а не на старые инструкции по именованию.

## Сборка из исходников

Для сборки требуются Windows, **Visual Studio 2022** с компонентами разработки на C++ (v143, VC Tools 14.44), Windows SDK и **PowerShell 7**. Для сборки установщика нужен NSIS. Windows 7 — целевая среда запуска готового приложения, а не среда разработки.

```powershell
git clone --recurse-submodules https://github.com/sklart/fictionbook-editor-next.git
cd fictionbook-editor-next

.\tools\build\build.ps1 -Configuration Release -Platform Win32 -SkipUpx
.\tools\build\verify-release.ps1 -Configuration Release
```

Для полной проверки перед выпуском применяется отдельный релизный контур; запускать его после каждой небольшой правки не требуется. Собранные бинарники размещаются в `out/Release`, пакетные артефакты — в `out/artifacts` после упаковки.
