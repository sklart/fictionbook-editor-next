# Каталог переводов окон плагинов

Этот каталог предназначен для будущего перевода окон плагинов через Weblate или
похожий инструмент.

Пока runtime-сборка использует Win32 `.rc`-файлы самих плагинов. Целевой формат
внешней локализации — JSON-файлы `Lang/<язык>/<плагин>.json`. Следующий шаг —
вынести переводимые подписи из `.rc` в стабильный текстовый каталог и либо
читать JSON в runtime, либо генерировать из него resource-фрагменты для сборки.
В обоих вариантах у каждого плагина должен оставаться встроенный fallback.

Планируемая структура ключей:

```text
export_docx.dialog.settings.caption
export_docx.option.export_images
export_epub.dialog.settings.caption
import_epub.error.stage.open_file
export_html.option.include_document_description
```

Требования к ключам:

- ключ не должен меняться при переформулировке текста;
- в ключе не должно быть координат, размеров и Win32-style флагов;
- один пользовательский текст — один ключ;
- если строка содержит имя формата (`FB2`, `EPUB`, `DOCX`), его лучше оставить
  неизменным во всех языках.

Целевые языки первого этапа:

- `en-US`;
- `ru-RU`;
- `uk-UA`;
- `de-DE`;
- `fr-FR`;
- `es-ES`;
- `it-IT`;
- `pl-PL`;
- `pt-PT`;
- `nl-NL`;
- `cs-CZ`;
- `bg-BG`.

## Текущий файл каталога

- `catalog.json` — первый машинно-проверяемый каталог строк окон плагинов.
  В нём уже заведены стабильные ключи для основных подписей `ExportHTML`,
  `ExportDOCX`, `ExportEPUB`, `ImportEPUB` и черновые переводы на целевые языки.
- `tools/tests/test-plugin-localization-catalog.ps1` проверяет, что у каждого
  ключа есть непустой перевод на все целевые языки. Этот тест подключён к
  `verify-release.ps1` как лёгкий release-gate.

Важно: каталог пока не генерирует `.rc` автоматически. Это сделано намеренно:
сначала фиксируем ключи и переводческий формат, затем отдельным этапом будем
подключать генерацию resource-фрагментов и проверять реальные размеры диалогов.

## Экспорт для переводчиков

Общий экспорт app/plugin-строк выполняется командой:

```powershell
.\tools\localization\export-weblate-seed.ps1
```

Результат появляется в `out\localization\weblate-seed` и предназначен для
вычитки или будущего подключения Weblate. Runtime-ресурсы плагинов пока из него
не генерируются.


## Runtime-цель

Планируемые файлы для установленной программы:

```text
Lang/<язык>/export-html.json
Lang/<язык>/export-docx.json
Lang/<язык>/export-epub.json
Lang/<язык>/import-epub.json
```

Если внешний JSON отсутствует или в нём нет конкретного ключа, плагин должен брать встроенную строку из DLL и продолжать работу.
