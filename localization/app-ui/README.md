# Локализация FBE и FBV

Этот каталог — подготовительный слой для будущего перевода основного интерфейса FictionBook Editor Next и FictionBook Validator.

Сейчас рабочая схема остаётся прежней:

- FBE использует ресурсные DLL `res_rus.dll` и `res_ukr.dll` из `src/locales`;
- FBV использует ресурсы `src/fbv/FBV.rc`;
- shell-команда проверки FB2 использует MUI-ресурсы;
- плагины ведутся отдельно в `localization/plugin-ui/catalog.json`.

`catalog.json` пока не заменяет `.rc`-файлы в сборке. Он фиксирует целевые языки, существующие источники и первые стабильные ключи, чтобы следующий шаг можно было сделать без хаоса: извлечь строки из `.rc`, отдать их в Weblate/другой инструмент перевода и постепенно перейти к runtime JSON-файлам `Lang/<язык>/fbe.json` и `Lang/<язык>/fbv.json` с обязательным встроенным fallback.

## Будущие языковые пакеты

Отдельная цель — сделать языки опциональными компонентами установщика. Тогда базовый язык и выбранный пользователем язык будут ставиться всегда, а дополнительные `res_*.dll` и `.mui` можно будет не устанавливать. Это уменьшит размер установки и сделает список компонентов понятнее для пользователей, которым не нужны все языки сразу.


## Fallback при отсутствии внешних файлов

Даже после перехода на JSON отсутствие `Lang/<язык>/fbe.json` или `Lang/<язык>/fbv.json` не должно ломать запуск. FBE и FBV должны использовать встроенные строки из `exe`/ресурсов, а внешний JSON рассматривать как переопределение.
