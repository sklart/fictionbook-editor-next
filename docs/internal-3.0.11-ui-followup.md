# Интерфейс внутренней сборки 3.0.11

## Ресурсы Description

После возврата прежнего интерфейса `DescriptionStyleBinary` не добавляет класс
`description-binary`: селекторы, устанавливавшие картинки кнопок из
`DescriptionIcons`, не применялись. Обычные кнопки просмотра, сохранения и
удаления создаются в `BuildBinaryControls` и используют прежние символы.
Каталог и правила включения в установщик удалены. Удаление старых файлов при
деинсталляции сохранено для предыдущих установок.

Отдельный runtime-сценарий нажимает кнопки просмотра и удаления, выбирает
обложку и сравнивает байты записи через штатный native writer. Для сохранения
он подставляет временный путь: интерактивный диалог «Сохранить как» этот
сценарий не проверяет. Save/Reopen Description и бинарных вложений проверяются
другими production-сценариями. Исходный тест ложного dirty остаётся неизменным
и по-прежнему сообщает об известном отказе.

## Палитры

Предварительное сравнение выполнено на снимках настоящего окна редактора схем,
включая его элементы управления и интерактивный образец. Среди прежних схем
Catppuccin Mocha, Frappé и Macchiato близки по холодному тёмному фону;
Solarized Light и Everforest Light имеют близкую бумажную основу. Существующие
схемы сохранены. Добавлены Forest (тёмно-зелёный), Plum (сливовый) и Turquoise
Light (светлая бирюза), отличающиеся фоном и элементами управления.

Проверенные отношения контраста для новых схем (соответственно Forest, Plum,
Turquoise Light): основной текст на фоне 13,61 / 13,42 / 10,18; текст на
элементе управления 11,04 / 11,16 / 8,82; выделение 6,65 / 9,18 / 6,41;
неактивный текст 6,03 / 6,43 / 3,82; ошибка 8,23 / 8,57 / 7,16;
предупреждение 11,06 / 11,31 / 7,15. Runtime-тест также проверяет фокус и
независимость сохранённой темы XML. Контрастные цвета подписей в образцах
подбираются по фону; цветовые роли самих схем не подменяются.

Окно управления сначала предлагает список с образцами и группами. Выбор
применяется к настройкам кнопкой «Применить»; подтверждение главного окна
настроек сохраняет его. Расширенный редактор открывается отдельно. При
редактировании встроенной схемы предлагается копия. Автоматический режим
Windows относится к классической схеме; другие схемы определяют светлый или
тёмный вид самостоятельно.

## Панель скриптов

Выделения двух списков независимы. Активное выделение заполнено, неактивное
обведено рамкой. Добавление использует первую выбранную позицию справа либо
конец панели, если она не выбрана. Перетаскивание слева направо принимает
позицию над или под строкой, включая пустую панель и область после последней
строки; внутреннее перемещение справа сохранено. Runtime-сценарии используют
реальные списки и уведомления, включая клавиатуру и перетаскивание.
Enter проверен, но Ctrl+стрелки в текущем изолированном контуре имеют статус
NOT RUN: Windows не сохранила синтетическое состояние Ctrl в очереди ввода.
Ожидание теста при доступном модификаторе не изменено; требуется ручной повтор.

Программная проверка геометрии охватывает 100%, 125%, 150% и 200%; это не
равнозначно ручной визуальной проверке на четырёх реальных системных масштабах.
Снимки диалогов и журналы приёмки поставляются с внутренним комплектом.
