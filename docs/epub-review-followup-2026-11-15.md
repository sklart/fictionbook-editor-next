# Доработка импорта EPUB по замечаниям

Титульный блок, если он включён и ещё не найден в начале книги, записывается в `body/title`: авторы в первом абзаце, название во втором. Сквозная нумерация примечаний остаётся настройкой: при её использовании технический заголовок, совпадающий с ID или состоящий из цифр, заменяется номером; содержательные заголовки сохраняются.

Изображения на краю абзаца с текстом выносятся в блок в поддерживаемых случаях. Текст и ID абзаца сохраняются, изображение в середине текста остаётся строчным. Для абзацев со стилем или языком и сложных вложенных конструкций преобразование консервативно; порядок и ограничения FB2 проверяются после преобразования.

Дата публикации с корректным временем выводится в виде календарной даты; исходная строка сохраняется в `custom-info`. Префикс `urn:uuid:` удаляется только у корректного UUID, исходный идентификатор также сохраняется в `custom-info`. Другие идентификаторы не переписываются. При уверенном противоречии языка `ru`/`en` выборке основного текста язык исправляется, исходное значение сохраняется в `custom-info`, а в журнале выводится предупреждение. Определение ограничено выборкой и не является универсальным распознаванием языков.

Настройки титульного блока, унификации примечаний и изображений, пустых строк и подзаголовков по-прежнему выключены по умолчанию. Неоднозначные примечания, неподдерживаемые конструкции CSS и якоря ссылок не исправляются догадками; ID, которые могут быть целями ссылок, не удаляются массово. Оригинальный EPUB автора замечаний и версия 2.0 скрипта `44_Исправить нумерацию сносок` для проверки и замены отсутствуют.
