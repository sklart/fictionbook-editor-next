# Повторная ревизия карточек скриптов

Исторический отчёт предыдущего этапа. Скрипт 64 затем исправлен и проверен с итогом PASS;
актуальные результаты — [буквальные пары](script64-literal-pairs-report.md).

Дата: 15 октября 2026 года. Обработаны все **579** карточек. Изменены **579**.
Массовая правка не меняет исполняемые байты JS, кодировки, BOM и окончания строк:
это проверяется при применении предложений и сверкой с `script-card-code-baseline.json`.

## Что исправлено

- Настройки: удалены 84 служебных/неиспользуемых поля; осталось 1717 параметров.
  Для 1119 параметров добавлены явные русские `title`. В частности, исправлены
  601–612, объединение стихов и замены из буфера. Значения `extracting` отделены
  от сохранённых настроек пользователя; числовые резервные значения приведены
  к типу результата унарного плюса или N100.
- Назначение: изменены 36 кратких описаний, 27 развёрнутых описаний и 52 области
  обработки. Исправлена инструкция одиночного переноса примечания: курсор нужен
  внутри notes/comments; альтернативная ветка от ссылки закомментирована.
- Инструкции: переработаны 54 карточки с шаблонными шагами. Для числовых скриптов
  указаны конкретный вид префикса, обработка целых абзацев и пустых строк.
- Авторство: 65 карточек хранят одно имя в разных ролях. Диалог показывает имя
  один раз со всеми ролями; записи схемы v1 сохранены для старых читателей.
  Наличие участников не скрывает надпись «Автор не установлен».
- Undo: общие сообщения о непроверенности убраны из всех полей карточек.
  Нет автоматической замены текста по именам API. Для читающих скриптов раздел
  скрыт; неподтверждённая группировка не превращается в обещание Ctrl+Z.
  В 92 карточках оставлены конкретные ограничения или граница внешних файлов.
  Отсутствие finally само по себе не выводится как установленный дефект.
- Отозваны 20 прежних замечаний анализа, связанных с присваиванием
  `inflateBlock(...) = true`. Это индексируемое COM-свойство с propget/propput
  и DISPID 3 (`src/contracts/fbe.idl:83–86`), а не обычный вызов JavaScript.
  История отозванных замечаний сохранена в `dismissedCodeIssues`.
- Зависимости: проверены известные пути и хеши ресурсов, включая HTML/JS.
  Прежняя обязательная зависимость
  `HTML/Расставить иллюстрации по заданным местам.html` отозвана: путь находится
  только в локальной невызванной функции MyMsgWindow, рабочий вывод использует MsgBox.
  Создаваемый `HTML/temp.html` не считается входной зависимостью.
- Неустановленная версия скрывается. Общий контракт window.external не менялся.

## Средства контроля

`audit-script-cards.py` отдельно сообщает структурную корректность,
актуальность хеша и состояние содержательной проверки. Добавлены диагностики
служебных/неиспользуемых настроек, отсутствующего title, повторяющихся имён,
противоречий выделения, технических Undo-текстов, неизвестных ресурсов и
несовпадающих хешей зависимостей. Лексическая маска учитывает регулярные выражения;
для настроек учитываются упоминания в перечисленных связанных файлах.

Эвристики не применяют исправления автоматически. Наличие двух вызовов API
не присваивает `verified_single_action`. Этот дополнительный статус схемы v1
разрешает текст «Изменения можно отменить одним действием (Ctrl+Z)» только после
отдельного подтверждения. Ни одному встроенному скрипту такой статус не присвоен.
Пустое описание Undo остаётся пустым, технический status вместо него не выводится.
Старые карточки и старое оформление настроек продолжают читаться.

## Остаточная неопределённость и дефекты

- Полнота зависимостей не заявлена для 69 карточек; это состояние информации,
  а не ошибка исполнения. 510 карточек имеют текущие проверенные зависимости;
  отсутствующих обязательных ресурсов больше нет.
- В 33 карточках автор не указан; у 23 атрибуция частичная. Эти статусы сохранены.
- 192 эвристических кандидата с return внутри интервала группировки требуют
  оценки вложенности и достижимости. Это не 192 доказанных дефекта Undo.
- Остальные предупреждения анализатора о настройках — кандидаты: имена флагов,
  счётчики в описании поведения и объявления в составных выражениях сами по себе
  не доказывают, что параметр служебный.
- Конкретные условия нарушения группировки перечислены в
  [отдельном списке](script-card-undo-defects.md). Полные записи анализа кода,
  включая вопросы для проверки и отозванные выводы, находятся в
  [проверенных предложениях](script-card-reviewed-proposals.json).
- `21_Поиск и замена/64_Замена символов по списку из буфера обмена.js`:
  лишний разделитель перед else удалён отдельной правкой после коммита метаданных
  `057e5ab9`. Изменён ровно один исполняемый байт, алгоритм не переписан.
  Стандартный JavaScript-парсер теперь принимает файл. 32-битный JScript принимал
  также исходную форму: прежний вывод о невозможности запуска в FBE отозван.
  Непустое выделение и формат списка замен уточнены в карточке.
  Новый SHA-256: `1f0c23c0fb935234675eb9b3c01a871065f66883ef399e17dc99f3ffcb36ff82`.
  На этапе `dc980695` проверялся только разбор. Фактический Run, отказы и обычный
  Ctrl+Z проверены в последующем точечном этапе; обнаружен дефект спецсимволов
  справа в паре. Подробности: [отчёт продолжения](script-card-followup-report.md).
  История: [отдельная правка](script-card-executable-repairs.json).
  `script-card-refinement-proposals.json` сохраняет снимок массовых правок
  до этой отдельной редакции исполняемого файла.

`sourceRevision.reviewStatus` везде сохранён `generated`. Ревизия не заявляет
проверку всех аварийных ветвей в настоящем JScript и полноценный Ctrl+Z всех
579 скриптов. Неизвестные версии и авторы не угадывались.

- Изолированный `script-card-dialog-runtime`, лимит 45 секунд — PASS.
  Проверены обычная карточка, настройки, русский и старый формат значений,
  объединение ролей, неизвестный автор, скрытый неподтверждённый Undo,
