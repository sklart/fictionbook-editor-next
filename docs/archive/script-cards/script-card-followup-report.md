## Ложная зависимость

В скрипте `05/15` MyMsgWindow локальна внутри Run. В исполняемом коде отсутствуют
вызовы или передача этой функции по ссылке; eval, Function и строковых таймеров нет.
Оба вызова MyMsgWindow закомментированы, штатный вывод использует MsgBox.
Поэтому удалены обязательный HTML и оба противоречивых предупреждения о нём.
`dependencies=[]`, `dependenciesComplete=true`, число непроверенных ресурсов — 0.
Фиктивный файл не создавался, функция и алгоритм не удалялись.

Анализатор показывает владельца найденного пути и консервативную достижимость:
`reachable`, `not_referenced`, `unknown`. Прямые ссылки, уходящие в callback,
динамическое выполнение и экспортируемые функции сохраняют неопределённость.
Даже наличие прямого пути не присваивает обязательность автоматически (`required=null`).
Эти случаи покрыты короткими регрессионными проверками.

Актуальные зависимости: **510 current, 69 unverified, 0 обязательных пропусков**.
Ни один из остальных неполных списков автоматически не подтверждался.

## Реальный запуск скрипта 64

Стенд запускает исходный Run через Doc::RunScript в изолированной portable-копии
FBE Next Win32 с настоящими MSHTML, JScript, выделением, буфером обмена и Undo.
MsgBox/alert перехвачены на границе стенда для неблокирующей проверки отказов.
Это не подмена алгоритма моделью JavaScript и не только проверка синтаксиса.

| Проверка | Результат |
|---|---|
| `abc ab`, пары `aA`, `bB` | PASS: `ABc AB` |
| Метасимволы слева `. + * ? ( ) [ ] ^ $ \| /` | PASS |
| Обратная косая черта и кавычка слева | PASS |
| Пустое выделение | PASS: сообщение, текст не меняется |
| Пустой список | PASS: сообщение, текст не меняется |
| Строка из трёх символов | PASS: отказ, текст не меняется |
| Одна обычная команда Ctrl+Z | PASS: `abc ab` восстановлен |
| Спецсимволы справа: строки `a$`, `b\`, `c"` | **FAIL**: «Незавершенная строковая константа», текст остаётся `abc` |

Итог функционального прогона сохранён **FAIL**. Успешные случаи не скрывают
обнаруженную проблему. Состояние буфера после завершающего прогона восстановлено;
первый вариант стенда, удерживавший исходный OLE-объект, не смог восстановить буфер
и был заменён предварительным копированием всех исходных форматов.

В карточке скрипта 64 добавлено конкретное ограничение спецсимволов справа,
уточнены многострочные поля и исключены однострочные. TEXTAREA отдельно в FBE
не запускалась; её поддержка следует из исходной ветви кода. Проверенный Ctrl+Z
не распространяется на все возможные ветви и поля; новый статус полного Undo
не присваивался. Исполняемый скрипт и API window.external не менялись.

[Результаты и хеши стенда/EXE/исполняемого JS](../../script64-runtime-results.json).
