# Классификация ограничений Undo

Классифицированы все 91 замечание исходного списка. Исполняемый JS не менялся.
Оценка основана на записанных условиях анализа; все аварийные ветви в FBE не воспроизводились.
Категории могут пересекаться; число назначений категорий не равно числу скриптов.

P1 — риск частичных/неохваченных изменений или незакрытой группы в рабочей ветви;
P2 — защитная ветвь при недоступной книге либо управление состоянием группы; P3 — название в истории.
