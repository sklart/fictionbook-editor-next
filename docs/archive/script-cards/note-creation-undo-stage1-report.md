# Создание примечаний и комментариев: этап 1 Undo

Дата: 16 октября 2026 года. Исправлены ровно 12 комплектных скриптов:
`02_Примечания/01–06` и `03_Комментарии/01–06`.

| Вариант | Назначение сохранено |
|---|---|
| 01 | Создать, остаться на ссылке |
| 02 | Создать с вводом текста |
| 03 | Создать и перейти к разделу |
| 04 | Добавить последнее, остаться на ссылке |
| 05 | Добавить последнее с вводом текста |
| 06 | Добавить последнее и перейти к разделу |

До открытия группы проверяются документ и положение курсора, body нужного типа,
вложенность секций, корректность существующих ссылок, уникальность исходных и
будущих ID. Место вставки, нумерация и изменения существующих ссылок/заголовков
планируются по сохранённым ссылкам на элементы. Затем полностью завершается
prompt/нормализация/miniValidate; отмена первого или повторного ввода не меняет книгу.
Только после согласия создаются отсоединённые элементы и открывается собственная
группа для изменения книги. Все прикреплённые изменения находятся в этой группе.

Созданная ссылка определяется по заранее свободному ID и служебному признаку;
затем хранится непосредственная ссылка. Поиск по тексту `Sclex_Note` удалён.
Чужая ссылка с этим текстом и элемент с занятым префиксом ID сохранены в тестах.
В finally закрывается только открытая этим Run группа. Незавершённая созданная
пара очищается по собственным ссылкам; завершённая корректная пара сохраняется
для отмены. При ошибке вставки между существующими разделами проверяется также
уникальность нового ID, чтобы не оставить созданный раздел с конфликтующим адресом.
Исходная ошибка сохраняется при сбое очистки; автоматического Ctrl+Z нет.

Настройки, авторство, версии и код вспомогательных преобразований перед новым
блоком сохранены; равенство исходного префикса проверено по байтам после
нормализации LF/CRLF и записано хешами. Сохранены различия notes/comments,
шаблоны ID/заголовков/содержимого/ссылок, lastSnoskaMode и MoveFocusToNote.
Forsazh сохраняет случайный ID и отсутствие перенумерации; обязательные проверки
безопасности структуры теперь действуют и в этом режиме. Описание настройки уточнено.

## Ограничения

Закрытие группы не откатывает уже применённые изменения. Проверенный частичный
результат после замены выделенного текста восстанавливается Ctrl+Z. При произвольном
исключении посреди перенумерации часть относящихся к сноскам ID/ссылок уже могла
измениться; автоматического отката нет. При отказе самих DOM-операций очистки или
EndUndoUnit удаление созданной разметки/закрытие группы не гарантируются.
Если DOM откажет сразу после pasteHTML и не позволит определить созданную ссылку,
безопасно удалить её по сохранённой ссылке также невозможно; чужие элементы
вместо неё не выбираются. Этот случай не включён в утверждение о полной очистке. Такие
отказы, нехватка памяти и все комбинации пользовательских шаблонов не объявляются
полностью атомарными. Статус карточек остаётся explicit_calls_found.

Реестр сохраняет исходные 91 замечание как историю: **12 исправлены, 79 остаются**.
Другие 567 исполняемых скриптов не изменены; остальные этапы не выполнялись.
