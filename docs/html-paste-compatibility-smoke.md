# Короткая ручная проверка вставки перед релизом

Заполнять на отдельной копии книги. Записать ОС, SHA сборки, имя/происхождение
FB2 и результат каждого пункта. Автоматический runtime не заменяет эту проверку.

| Действие | Ожидаемый результат | Результат |
| --- | --- | --- |
| HTML и многострочный обычный текст: начало, середина, конец абзаца | Текст по обе стороны сохранён; пустая строка и соседние секции не повреждены. Paste Text игнорирует HTML буфера | NOT RUN |
| Копирование внутри FBE: strong/em/code и действующая ссылка | Форматирование и ссылка сохранены; переход по ссылке работает | NOT RUN |
| Предыдущая правка, затем 2–3 Ctrl+V, по одному Undo и Redo | Порядок верный; один шаг на вставку; предыдущая правка отменяется отдельно; каретка возвращается | NOT RUN |
| Перетаскивание текста внутри секции и между секциями | Правильная точка переноса; один Undo возвращает источник и назначение; Redo повторяет перенос | NOT RUN |
| Validate, Save, закрытие, Reopen реальной FB2 | Валидация успешна; нет потери текста, форматирования, изображений и ссылок; после сохранения документ чистый | NOT RUN |
| Та же проверка на копии книги, созданной FBE 2.8.5 | Сохранение и повторное открытие без потерь; исходный файл сохранён отдельно | NOT RUN |
| Повторить на Windows 7 при наличии среды | Те же результаты, без ошибок запуска и вставки | NOT RUN — тестовая среда Windows 7 не предоставлена |

Для проверки обычного текста положить в буфер одновременно HTML и текст и
выполнить «Вставить как обычный текст». Для серии Ctrl+V отдельно попробовать
неизменный буфер и смену содержимого между вставками. Признак dirty должен
появляться после каждой правки и исчезать после Undo к сохранённому состоянию.
После серии команд следующий Undo не должен быть пустым шагом.
