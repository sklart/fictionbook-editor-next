Для каждого этапа сначала один представитель, затем родственные варианты после
сверки их ветвлений. Не вставлять try/finally механически: закрытие группы
не откатывает частичные изменения и не отменяет вложенные группы. Сначала
установить, кто открывает и закрывает группу, где появляются временные узлы и
когда спрашивается пользователь. Отдельно решить требование атомарности отказа.
Не вызывать Ctrl+Z автоматически из finally: это может отменить чужую операцию.

Готовность этапа: штатный результат сохранён, отказ до мутаций ничего не меняет,
незакрытой группы и маркеров нет; Undo/Redo проверены в MSHTML на изолированной
истории. Повышать статус карточек только для фактически проверенных контуров.
