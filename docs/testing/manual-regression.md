# Общая ручная регрессия FBE Next

> Тип: действующий чек-лист, не результат прогона. База документации: 3.0.9 / `1ad7c507d1edcd0ca132589fe5a9f16a5574253d`, 19 октября 2026 года.

## Как заполнять

Используйте отдельные копии книги и изолированные installed/portable-окружения. До сценариев отказа сделайте резервную копию. Запишите ОС, разрядность, build SHA, DPI, тему, язык, режим установки, fixture и фактический результат. `NOT RUN` не заменяется PASS по одной успешной сборке.

Этот документ сохраняет **всю прежнюю программу** проверки, а ниже дополняет её новыми сценариями 3.0.9. Старые проверки открытия, редактирования, структуры, ссылок, таблиц, изображений, экспорта, FBV и интеграции не удалены.

## Минимум перед выпуском

Пройти обычное открытие/редактирование/сохранение/reopen; проверить предшествующую правку + новую операцию + Undo/Redo; ZIP; предпросмотр массовой замены; отказ/отмена экспорта; installed/portable-изоляцию; диагностический пакет без текста книги и без DMP. Затем выполнить все дополнительные проверки, затронутые изменениями выпуска.

Полная Windows 7/UAC/DPI-матрица требует соответствующей среды. Причина невыполнения фиксируется отдельно.
