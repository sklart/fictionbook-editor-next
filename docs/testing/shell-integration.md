# Единая ручная матрица Shell-интеграции

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Подготовка

Используйте изолированную Windows/VM и известное исходное состояние регистрации. Запишите разрядность Проводника, Windows/MUI, режим установки, выбранные компоненты, commit и SHA DLL. Не проверяйте случайную DLL из `runtime` поверх чужой установленной версии.

Повторяемые процедуры установки и восстановления приведены в [installer maintenance](../reference/installer-shell-maintenance.md). Прежние подробные чек-листы сохранены в [архиве Shell](../archive/shell/README.md).

## Матрица

| ID | Действие | Ожидаемый результат | Факт |
| --- | --- | --- | --- |
| SH-01 | Установить выбранные Shell-компоненты в поддерживаемом режиме | Регистрация, разрядность, schema и receipt согласованы | NOT RUN |
| SH-02 | Открыть FB2 со стандартными метаданными в Explorer | Поля соответствуют книге; нет падения Explorer | NOT RUN |
| SH-03 | Проверить серию без номера и с номером | Отображение соответствует FBE-specific mapping | NOT RUN |
| SH-04 | Кириллица, несколько авторов, пустые поля, длинные значения | Корректный Unicode и мягкая обработка отсутствующих данных | NOT RUN |
| SH-05 | Проверить локализованные подписи в RU/EN MUI | Корректные названия без смешения stale schema | NOT RUN |
| SH-06 | PNG с alpha, непрозрачный PNG, JPEG/BMP | Миниатюра, прозрачность и пропорции соответствуют обложке | NOT RUN |
| SH-07 | Размеры 32/64/128/256/512, маленькое исходное изображение | Правильный downscale, нет обещания upscale | NOT RUN |
| SH-08 | Нет coverpage/binary либо обложка повреждена | Мягкий отказ, fallback-иконка, Explorer стабилен | NOT RUN |
| SH-09 | Прямой COM/shell extraction и показ в Explorer | Отдельно записаны результаты provider и UI-кэша | NOT RUN |
| SH-10 | Повторно открыть/обновить каталог с несколькими FB2 | Нет падения и утечки ресурса в наблюдаемом сценарии | NOT RUN |
| SH-11 | Обновить installed-версию при занятых DLL | Понятный pending/error, сохранено владение компонентами | NOT RUN |
| SH-12 | Выполнить штатное восстановление интеграции | Известный итог без чужих регистраций | NOT RUN |
| SH-13 | Удалить выбранную installed-копию | Удалено только принадлежащее ей; нет разрушения чужих ассоциаций | NOT RUN |
| SH-14 | Запустить portable рядом с установленной копией | Нет самовольной системной интеграции | NOT RUN |
| SH-15 | Проверить upgrade legacy ArchHandler | Пользовательские ассоциации .zip/.rar не подменены | NOT RUN |

## Интерпретация

Успех одного COM-вызова не заменяет прохождение installer/Explorer/MUI-матрицы. Очистка thumbnail cache применяется только для диагностики stale результата и записывается отдельным действием.

Заполняйте фактическую колонку только после проверки соответствующей сборки. В этой поставке документов все строки оставлены `NOT RUN` намеренно.
