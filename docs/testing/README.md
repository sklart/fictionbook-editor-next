# Тестирование и доказательства

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

[Выбор контура](../test-contours.md) объясняет LOCAL/STAGE/RELEASE и FAST/FULL. [Общая ручная регрессия](manual-regression.md) сохраняет прежнюю широкую программу и добавляет актуальные сценарии 3.0.9.

| Подсистема | Чек-лист |
| --- | --- |
| Поиск и замена | [Regex](regex-regression.md), [правила fixture](regex-fixtures.md) |
| Орфография | [Spellcheck](spellcheck.md) |
| Исходный XML | [Source](source-editor.md), [DirectWrite](source-directwrite.md) |
| Системная интеграция | [Shell](shell-integration.md) |
| Вставка/перенос/история | [HTML Paste](html-paste.md) |
| Выделение изображения и scrollbar | [MSHTML regression](image-selection-scrollbar.md) |

[Статус проверок](verification-status.md) — сводка областей и пробелов, не журнал всех команд подряд. [Рабочие отчёты](reports/README.md) сохраняют незавершённую приёмку. [Evidence](evidence.md) перечисляет контрольные данные, которые нельзя удалять или форматировать при переносе документов.

В каждую запись результата входят build SHA, ОС, конфигурация, фактическая команда/действие, результат, ограничения и ссылка на артефакт. Непроведённая проверка отмечается `NOT RUN`, невозможная из-за среды — `BLOCKED`; ни одна из них не превращается в PASS автоматически.
