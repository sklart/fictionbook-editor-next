Статус issue проверяется в GitHub, а не выводится из слова «завершено» в заголовке одного этапа. После принятия всей задачи отчёт можно перенести в тематический архив, сохранив ссылку и build SHA.

Исследования и воспроизводимые исторические проверки с самостоятельной ценностью перечислены в [архиве](../../archive/README.md). Не объединяйте разновременные PASS в одно недатированное утверждение о текущем master.
