# FBE Next 3.0.11 — решение о выпуске

**Актуализация 21.11.2026:** внутренний RC2 находится в `dist/internal-3.0.11-rc2/`; контрольные суммы двух пакетов совпадают с `SHA256SUMS.txt`. Исходный кандидат — `3f635f8479f21aab9671baee488aeb9a60fca6da`; последующие исправления проходят приёмку. На изменённой сборке выполнены адресные проверки, но окончательные P0 FULL, ASan/UBSan FAST и проверка пакетов нового SHA не проведены. RC3 не создан; публичный выпуск — **NO-GO**. Ниже сохранён исторический снимок предыдущего этапа, включая устаревшее утверждение о том, что RC2 не сформирован.

Дополнительный дефект P0 Recovery **подтверждён на тестовых данных**: после снимка архива A, открытия B и отказа записи sidecar восстановление получило книгу B с адресом A; обычный Save изменил A, а B остался неизменным (`out/recovery-mismatch-probe.log` в основном дереве). Подготовленная защита удаляет старую идентичность до замены снимка и проверяет SHA-256 снимка перед принятием новой идентичности; устаревший формат метаданных восстанавливается как отдельный документ. Адресные проверки проведены, полный релизный gate остаётся открытым.

Дата: 21.11.2026. Базовый кандидат: `7e3dc3755e40c8e4fbff6ee8f7b45d6b873437b4`. Работа по приёмке продолжается; итоговый SHA исправлений ещё не зафиксирован. Текущий статус: **NO-GO**, внутренний RC2 не сформирован.

1. Подтверждённый P0 поздней правки исправлен только в незакоммиченном кандидате; финальный SHA и обязательный P0 gate на нём отсутствуют. Пути ZIP и скриптового API для поздних правок требуют отдельной проверки.

3. Финальные Win32-сборка, полный gate, одинаковые проверки с 3.0.10 и Portable/Installer на одном SHA не выполнены; это пробелы приёмки, а не подтверждённые новые дефекты.

Публичный релиз, тег и push не выполнялись. Ручной FULL и финальные пакеты NOT RUN. Наличие запуска с итогом `INCOMPLETE` не является успешной полной приёмкой.
