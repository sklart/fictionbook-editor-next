# Памятка по изменению переводов

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Где искать источник

Основная схема локализации описана в [полном справочнике](localization.md). Runtime-контур использует `Lang/<locale>/<module>.json`; безопасные встроенные ресурсы служат fallback. Сохраняйте stable keys и действующую структуру каталогов/генераторов.

Не редактируйте только готовый runtime JSON, забывая о сопровождаемом каталоге, из которого он получается. До изменения найдите producer, fallback и потребителей ключа. Добавление строки включает её проверку в соответствующих языковых пакетах.

## Что проверять

Плейсхолдеры форматирования, мнемоники меню, Unicode, длинные переводы, ширину/высоту контролов, всплывающие подсказки и пустой/повреждённый пакет. Переключение языка не должно оставлять часть открытого интерфейса со случайным прежним текстом.

Локализация не является разрешением менять command IDs, смысл опций, поведение скриптов или править исходные авторские комментарии. Перевод карточки и изменение исполняемого кода должны оставаться разными операциями.

## Приёмка

Выполните актуальный localization preflight и адресные UI-проверки для затронутого модуля. Один source-contract не подтверждает отсутствие обрезанного текста. Зафиксируйте язык, DPI, тему и сборку.

Упоминание возможного Weblate в техническом документе описывает направление развития, а не наличие действующего сервера или настроенной интеграции. Не выдавайте планируемое подключение за существующий рабочий процесс.
