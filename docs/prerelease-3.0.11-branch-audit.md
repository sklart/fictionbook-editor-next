## Независимая оценка PR #62

[PR #62](https://github.com/sklart/fictionbook-editor-next/pull/62), head `cd356573d15692657fb16126cd1e528de82e7bb2`, открыт; источник — ветка New_script чужого форка MiFodiyUNO. Он добавляет HTML-диалог, JS и ICO для работы с секциями, а не исправление обязательного сценария 3.0.11. Действий с PR и чужой веткой не выполнялось.

В доступном diff ветка createSectionFromSelection внутри section не использует selectedHtml и вызывает splitSectionAtCursor; та переносит целый непосредственный дочерний узел и последующие узлы, а не делит текст по каретке. Очистка форматирования обрабатывает A и SPAN как снимаемое оформление и выбирает пересекающиеся структурные DIV целиком; это создаёт риск изменения ссылок-примечаний, inline-изображений и содержимого за границей выделения. Первые операции открывают Undo без finally при исключении. В публичном IDL и таблице имён ExternalHelper текущего кандидата IsXML не найден; реакция JScript на проверку отсутствующего свойства отдельно не проверялась.

На PR уже есть review CHANGES_REQUESTED от 05.10.2026 с сообщением о шести воспроизведённых сценариях; это историческое свидетельство автора review, не новый runtime-тест на 0822b3df. PR не включать в релиз без отдельной переработки и проверки, сохранить открытым.
