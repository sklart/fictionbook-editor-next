# EPUB: результаты проверки изменений

Проверка выполнена в отдельной чистой рабочей копии. Строгая сборка полного
`FBE.sln` Release Win32 с v143 и `FbeStrictWarnings=true` прошла; до этого
первый запуск остановился из-за полного диска и был повторён после очистки
устаревших промежуточных сборок. Внешняя библиотека Hunspell выдала своё
предупреждение компилятора; правила предупреждений первого уровня к vendor
не применялись. Собственный код из изменений EPUB собран без ошибок.

На той же сборке прошли:

- 21 адресная проверка безопасной распаковки ZIP, включая 7z-сигнатуру,
  Unicode, CP437, ZIP64, дескрипторы данных и повреждённые архивы;
- тест ограничений путей, обязательных ресурсов и очистки reparse point;
- 19 проверок структуры и содержания EPUB/FB2 и ещё четыре проверки журналов,
  предупреждений и CSV/HTML; независимая XSD-проверка полученных FB2;
- ExportEPUB v2 и batch для EPUB 2/3, безопасная замена целевого файла,
  проверка Deflate и журнала ошибок исходных ссылок;
- ImportEPUB v2 runtime и автоматическое сохранение/повторное открытие FB2 в
  изолированном экземпляре редактора;
- тест ZIP-экспорта под Windows PowerShell 5 и PowerShell 7. Для обоих
  исправлены исходная кодировка сценария и несовместимый вызов .NET API.

Результаты реальных EPUB и замеры описаны в документах этапов 1, 3, 4 и 5.
Весь EPUB-корпус и работа на Windows 7 SP1 не проверялись. Буфер обмена не
использовался.

Полный `verify-release.ps1` **не пройден**. На этой машине локализационный
preflight остановился из-за отсутствия Python Launcher `py.exe`; повторный
вызов с его пропуском прошёл 24 синтетические проверки обновления зависимостей
и остановился на отсутствующем манифесте provenance полноценного сборочного
конвейера. Интерактивные проверки буфера и Split/Undo были явно пропущены.
Прямой MSBuild не подменяет авторитетный выпускной конвейер и его provenance.

Диагностика улучшена, но не полностью унифицирована: достоверные отдельные
счётчики всех обратных и исправленных ссылок и всех случаев потери оформления
или семантики ещё не реализованы. Реального примера повреждённого EPUB именно
с декларацией Windows-1251 в просмотренной выборке не найдено; эта регрессия
подтверждена синтетическим воспроизведением.
