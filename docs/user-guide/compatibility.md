# Совместимость и границы проверки

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Целевая платформа

Основной редактор — Win32/x86, с MSHTML/OLE и целевой совместимостью Windows 7 SP1 и новее. Отдельного штатного XP/Vista-выпуска в рассматриваемой базе нет. Этот документ не вводит обещание такого выпуска.

Универсальная сборка редактора не исключает раздельных shell DLL под разрядность Проводника. Совместимость внешнего бинарного плагина проверяется отдельно от совместимости JS-скрипта.

## Цель не равна результату испытаний

| Утверждение | Что оно подтверждает |
| --- | --- |
| Проверены PE imports / Win7 policy | Использование контролируемого набора импортов в проверяемых бинарниках. |
| Пройден source-contract | Наличие проверяемой структуры/условия в исходниках. |
| Пройден runtime на одной ОС | Только записанный сценарий в указанном окружении. |
| Пройдена визуальная DPI-матрица | Только фактически проверенные масштабы, темы и переходы. |

Не объявляйте Windows 7, интерактивный UAC или перенос окна между мониторами проверенными только по успешной современной сборке. Для каждого выпуска нужен собственный [реестр проверок](../testing/verification-status.md).

## Скрипты, Source и Undo

Скрипты выполняются под Microsoft JScript/MSHTML. Современный JavaScript из браузеров и Node.js не является гарантированно поддерживаемым синтаксисом. Наличие метода проверяйте через API, а не по строке версии редактора.

Старые скрипты могут иметь собственные ограничения отмены. В частности, нельзя обобщать результаты адресных исправлений на весь комплект скриптов. Семантика структурной команды Split имеет отдельные ограничения; см. [Undo](../architecture/undo.md).

## DirectWrite

Наличие API DirectWrite не означает его включения в FBE по умолчанию. Решение привязано к [ручной матрице](../testing/source-directwrite.md), измерениям и текущему коду, а не к наличию поддержки у библиотеки.
