# Безопасное сохранение, резервные копии и recovery

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Три разных механизма

**Безопасная запись файла** защищает уже существующий результат при ошибке операции сохранения. **Резервная копия `.bak`** хранит предыдущую редакцию при включённом соответствующем параметре. **Recovery** помогает восстановить незавершённую работу после нештатного завершения. Один механизм не заменяет остальные.

Для обычного документа используется подготовка временного файла и последующая замена целевого. При включённом `CreateBackupFile` перезапись существующего документа формирует `.bak`; первое сохранение нового файла не обязано создавать такую копию. Отключение этой настройки не означает отключения безопасной записи и не является командой удаления старого `.bak`.

## После сбоя

Сохраните исходную книгу, recovery и диагностические файлы. При восстановлении проверьте текст, изображения, ссылки и валидность документа, затем сохраните результат в понятное место. Не считайте наличие recovery подтверждением успешной записи основного файла.

Временно невалидный Source требует особого внимания: аварийная копия может быть полезна для спасения текста, но не является автоматически корректным FB2. Исправляйте структуру на копии и проверяйте её валидатором.

## Экспорт

HTML, DOCX и EPUB используют подготовку результата до замены существующего файла. Для многофайлового HTML обычная обработка отказа и абсолютная атомарность при отключении питания — разные гарантии. Не обещайте атомарность всего набора при внезапном завершении процесса.

## Минимальная проверка

Обычное сохранение, read-only/ошибка доступа, отмена Save As, существующий `.bak`, сохранение книги в ZIP, штатный повторный запуск и восстановление после аварии проверяются раздельно. После отказа не должен появляться ложный чистый/сохранённый статус документа.
