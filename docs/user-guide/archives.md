# Работа с книгами в ZIP и RAR

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Открытие

FBE.exe непосредственно открывает поддерживаемые ZIP/RAR-контейнеры, включая составные расширения вроде `.fb2.zip` и `.fb2.rar`. При нескольких подходящих книгах выбирается нужная запись. Старый отдельный ArchHandler не является частью текущей поставки.

Поддержка открытия контейнера не означает одинаковую поддержку записи для всех форматов. В выпуске 3.0.9 основной описанный сценарий изменения книги внутри архива — **ZIP**. Для RAR не обещайте запись на месте без подтверждения соответствующего сценария; при необходимости сохраните отдельный FB2 или другой явно поддерживаемый результат.

## Сохранение изменений

Перед массовой правкой сохраните копию исходного архива. После изменения книги убедитесь, что сохраняете выбранную запись и ожидаемый контейнер, а не другую книгу из того же архива. При сообщении о внешнем изменении файла не подтверждайте перезапись, не разобравшись в причине.

После сохранения повторно откройте книгу из архива и проверьте текст, изображения и ссылки. При ошибке записи документ не должен объявляться успешно сохранённым; не закрывайте единственную копию с несохранёнными изменениями.

## Не переносить настройки между форматами механически

Резервная копия, recovery и безопасная замена файла решают разные задачи. Поведение обычного FB2, ZIP и «Сохранить как» проверяется отдельно. Нельзя выводить поддержку шифрованных, многотомных или произвольных иных архивов из общего названия ZIP/RAR.

## Что указать в сообщении об ошибке

Расширение контейнера, количество FB2 в нём, выбранную запись, действие Open/Save/Save As, наличие внешних изменений, точное сообщение, build SHA и воспроизводимость. Исходный архив передавайте только с учётом конфиденциальности.
