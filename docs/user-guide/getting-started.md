# Начало работы

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Выбор поставки

Обычный установщик предназначен для installed-версии и выбранной системной интеграции. Portable ZIP распаковывается целиком; запускается `FBE.exe`, а изменяемые данные хранятся в каталоге этой копии. Установщик также поддерживает создание portable-копии. Поэтому источник поставки (setup/portable ZIP/собственная сборка) и режим запуска (installed/portable) указываются отдельно. Версия Windows описывает среду, а не тип пакета.

Для installed-режима различаются установка текущему пользователю и всем пользователям. Повышение прав и набор доступных компонентов зависят от выбранного режима. Простая распаковка portable ZIP сама по себе не назначает FBE приложением по умолчанию и не устанавливает расширения Проводника.

Все основные EXE редактора выпуска 3.0.9 имеют архитектуру Win32/x86. Это не означает, что требуется 32-разрядная Windows. Границы — в [совместимости](compatibility.md).

## Первый документ

Работайте с копией книги, пока осваиваете команды. Откройте FB2/FBD и используйте три представления: «Тело» для визуальной правки, «Описание» для метаданных, «Код» для XML. После структурной правки проверьте документ и сохраните его. Отдельный анализ качества FB2 дополняет, но не заменяет валидацию.

Для книг в контейнерах см. [архивы](archives.md). Для преобразований в EPUB, DOCX и HTML см. [плагины](../plugins/README.md).

## Обновление и перенос

Проверка обновлений доступна из окна «О программе»; стабильный и предварительный каналы различаются. Перед обновлением сохраните документы. При переносе portable-копии сохраняйте вместе с программой её каталог `Data` либо настроенный `DataPath`.

Не смешивайте portable-данные разных копий случайным копированием только части каталога. Перед изменением installed-настроек сделайте резервную копию пользовательского каталога. Точные пути приведены в [настройках](settings.md).

## Когда что-то пошло не так

Не удаляйте книгу, recovery или диагностические файлы в надежде исправить проблему. Зафиксируйте последовательность действий и воспользуйтесь [инструкцией сообщения об ошибке](../reporting-issues.md).
