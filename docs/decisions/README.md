# Записи архитектурных решений

Здесь хранятся короткие решения, которые меняют границы компонентов, граф
сборки или правила происхождения артефактов. Каждая запись должна содержать
контекст, принятое решение, совместимые альтернативы и последствия.

Структурная модернизация фиксирует решения небольшими отдельными записями;
план аудита и release notes не заменяют решение.
