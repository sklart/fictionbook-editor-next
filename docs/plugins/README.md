# Импорт, экспорт и пакетные конвертеры

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

| Операция | Документ |
| --- | --- |
| FB2 → HTML | [ExportHTML](export-html.md) |
| FB2 → DOCX | [ExportDOCX](export-docx.md) |
| FB2 → EPUB 2/3 | [ExportEPUB](export-epub.md) |
| EPUB 2/3 → FB2 | [ImportEPUB](import-epub.md) |

Штатные DLL размещаются в `Plugins`, пакетные EXE имеют отдельные точки запуска. Для обычной работы встроенных плагинов в portable не требуется вручную регистрировать каждую DLL как legacy COM-компонент.

Открытие FB2/FBD и книги из поддерживаемого архива — не тот же самый контур, что импорт EPUB. Результат конвертации проверяйте в целевом формате и отдельно после обратного открытия, если такой round-trip предусмотрен.

У каждой утилиты собственные параметры. Не конструируйте командную строку одной batch-утилиты по аналогии с другой: используйте её актуальную справку и примеры соответствующего документа.

**Сохранность:** при ошибке или отмене экспорта прежний существующий результат не должен объявляться успешно заменённым. У многофайлового HTML отдельно учитываются частичный отказ и отсутствие гарантии атомарности всего набора при отключении питания.

## Где сохраняются настройки DLL

Portable-плагины используют `DeploymentContext::SettingsDirectory()` и отдельные
UTF-8 JSON-профили с `schemaVersion: 1`:

```text
Data/Settings/Plugins/import-epub.json
Data/Settings/Plugins/export-html.json
Data/Settings/Plugins/export-docx.json
Data/Settings/Plugins/export-epub.json
```

Параметры находятся в объекте `values`: прежние DWORD записываются целыми
числами (флаги — `0`/`1`), строки — строками JSON. Например:
`{"schemaVersion":1,"values":{"ImportImages":1,"SvgConversionMode":0}}`.

Если в `portable.ini` задан другой `DataPath`, используется этот каталог вместо
`Data`. Копируйте его вместе с программой. Загрузка DLL не создаёт профиль или
HKCU-ключ; настройки читаются при обращении к ним. Сохранение выполняется через
временный файл рядом с JSON с последующей атомарной заменой. Ошибки чтения,
повреждённый/неподдерживаемый JSON, отказ записи и конфликт сохранения сообщаются
вызывающему коду или диалогу; повреждённый профиль автоматически не заменяется
значениями по умолчанию. Не редактируйте профиль одновременно с открытыми
настройками плагина. Ревизия профиля фиксируется при открытии окна: если другой
экземпляр сохранил изменения, подтверждение старого окна не перезапишет их.
Сообщение оставляет введённые значения в окне. Для загрузки новых параметров
отмените изменения и откройте настройки повторно. При отказе записи можно
устранить причину и повторить сохранение, не вводя значения заново.

Положение и размер каждого из четырёх окон запоминаются при закрытии, включая
«Отмена» и крестик. При первом открытии окно центрируется на экране. При смене
DPI размер масштабируется, а при отключении монитора окно возвращается в
доступную рабочую область. Portable хранит геометрию отдельно от параметров
преобразования в `Data/Settings/Plugins/plugin-windows.json` с учётом `DataPath`;
Installed — в `HKCU\Software\FBETeam\FictionBook Editor Next\PluginWindowPlacement`.
Запоминание геометрии не подтверждает отменённые параметры преобразования.

Локализация загружается при обращении к плагину, вне `DllMain`. Сначала
используется языковой пакет рядом с DLL, затем общий каталог `Lang` рядом
с FBE. Собственные подписи кнопок плагинов не заменяются подписями системных
диалогов. Вкладки EPUB используют палитру текущей темы редактора.

HTML сохраняет выбор XSL, CSS и остальные параметры в `export-html.json`.
Пути к XSL/CSS внутри portable-копии записываются относительно её корня;
сами файлы остаются по выбранным путям. Для переносимости храните свои шаблоны
и их зависимости внутри переносимого каталога, например в
`Data/Settings/Plugins/Templates`. Внешний абсолютный путь остаётся внешним:
миграция настроек не копирует произвольные шаблоны, CSS и XSL include/import.
Штатный `html.xsl` определяется для текущей DLL; разрешение шаблона не меняет
реестр или JSON.

Installed сохраняет прежние HKCU-ключи под
`Software\FBETeam\FictionBook Editor Next`:

| Плагин | Прежний подраздел |
| --- | --- |
| ExportHTML | `PluginSettings\ExportHTML` |
| ExportDOCX | `ExportDOCX` |
| ImportEPUB | `ImportEPUB` |
| ExportEPUB | `Plugins\ExportEPUB` |

Portable не подхватывает их автоматически. Для явного переноса в конкретную
копию закройте её FBE и запустите из репозитория в PowerShell 5.1 или новее:

```powershell
.\tools\settings\import-plugin-settings.ps1 -PortableDirectory 'D:\Books\FBE Next'
```

Можно выбрать один профиль параметром `-Plugin export-html`. Скрипт читает
32-разрядное представление HKCU, учитывает `DataPath`, не изменяет старые ключи
и отказывается перезаписывать существующий JSON. Явное согласие на замену
задаётся параметром `-ReplaceExisting`; предварительный просмотр — `-WhatIf`.
Каждый файл переносится отдельно. При ошибке замены оставшаяся `.bak` сохраняется
для ручного восстановления. Работа самих DLL сохраняет поддержку Windows 7 SP1;
скрипт миграции требует PowerShell 5.1 и не предназначен для PowerShell 2.0.
