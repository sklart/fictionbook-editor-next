20 октября 2026 года структура интегрирована в `aa781b6f591980b3199a3a81798607b03364e4f8`. [Отчёт](integration-2026-10-20.md) описывает выбранные изменения, проверки и ограничения. Сборщик `assemble-docs.py` не поставляется в репозитории; прежняя команда сборки внешнего пакета не является текущей инструкцией.

## Правила последующих переносов

Сначала сравните Git-базу пакета, HEAD и рабочее дерево. Проверьте каждый исходный файл по [карте](file-map.json), отдельно рассмотрите документы, изменённые после базы. Не заменяйте каталог целиком. Сохраняйте полные исторические материалы и файлы-указатели; обновляйте относительные ссылки и проверяйте контрольные данные до удаления старого пути.

Актуальный `scripting-api.md` сохраняет все 88 методов API 1.3.0 из master. Из архива принята только исправленная ссылка оглавления. Исходные контрольные JSON, reviewed proposals и исполняемые скрипты не переписываются; старые отчёты не подтверждают новую сборку.

## Инструменты

`tools/audit-script-cards.py` пишет производные отчёты в `out/reports/script-cards`, ищет Git в PATH и строит HTML-ссылки относительно выбранного каталога. Вывод внутрь docs запрещён. Baseline, reviewed proposals и runtime evidence сохраняют прежние контрольные значения.

Проверки документации находятся в [tools/docs](../../tools/docs/README.md), отдельный workflow — `.github/workflows/docs.yml`. Они не запускают приложение и не заменяют release gate.
