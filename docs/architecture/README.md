Публичный контракт `window.external` остаётся в [scripting-api.md](../scripting-api.md). Внутреннее устройство backend не должно подменять справочник всех методов. Результаты прогонов ведутся отдельно в [тестировании](../testing/verification-status.md).

Архитектурный документ описывает действующее разделение ответственности. Предложение будущей реализации должно иметь статус «План» и не превращаться в утверждение о текущем runtime. Подробные исторические исследования находятся в [архиве](../archive/README.md).
