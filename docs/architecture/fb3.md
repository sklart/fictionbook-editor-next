# Поддержка FictionBook 3

FB3 представляет собой ZIP-пакет OPC. Корневая связь `Book` указывает на описание, а связь `body` в описании указывает на текст книги. Корневая связь `metadata/thumbnail` может указывать на обложку. Связи `image` в части текста сопоставляют идентификаторы изображений с частями пакета. Тип части берётся из `[Content_Types].xml`. Эти правила проверены по официальному конвертеру и примерам. [FB3, ревизия 92bdc0d](https://github.com/gribuser/FB3/tree/92bdc0d1fe89d9ac122ad342fd3c4cdc81a11c24)

Чтение разрешает связи в пределах пакета и выдаёт проверенные части для преобразователя. Результат преобразования в FB2 будет передаваться в редактор через существующий интерфейс импорта. Общий ZIP-распаковщик сохраняет ограничения и тестовый режим импорта EPUB. FB3 использует отдельные лимиты в 64 МиБ на часть, 256 МиБ на пакет и 20 000 записей. Текстовые XML-части ограничены 16 МиБ и глубиной 192. Внешние цели связей сохраняются как адреса без сетевых запросов.

## Источники и лицензии

- Нормативные XSD разрешено распространять в неизменном виде с уведомлением об авторских правах, условиями и отказом от гарантий. При подключении валидации нужно поставлять все используемые локальные зависимости схем и сохранять их исходные уведомления. [Условия LitRes](https://github.com/gribuser/FB3/blob/92bdc0d1fe89d9ac122ad342fd3c4cdc81a11c24/license.txt)
- Официальные Perl-сценарии и XSLT под LGPL-3.0 использованы как эталон преобразования. Сценарий импорта обрабатывает связи, перекладывает идентификаторы заголовков, переносит подписи таблиц, собирает изображения и только затем применяет XSLT. В FBE обработку пакета реализует собственный C++-код. [Лицензия конвертера](https://github.com/gribuser/FB3/blob/92bdc0d1fe89d9ac122ad342fd3c4cdc81a11c24/api/perl/FB3-Convert/README) · [Официальный импорт](https://github.com/gribuser/FB3/blob/92bdc0d1fe89d9ac122ad342fd3c4cdc81a11c24/api/perl/FB3-Convert/bin/fb3_to_fb2.pl)
- FB3Tools использует Windows OPC API для поиска связанных частей. DirtyFb3Converter независимо разрешает ссылки на описание и обложку, а также читает типы ресурсов. FB3Editor и FB3Reader использованы как справочные реализации обработки содержимого и связанных изображений. Код этих проектов в FBE не переносился. [FB3Tools](https://github.com/evpobr/FB3Tools/tree/2ee735b480cd0c215947782e78d9f4bc9a163826) · [DirtyFb3Converter](https://github.com/alm-2000/DirtyFb3Converter/tree/6056e8fb0471e8a0b8e3ee32d6042f738d04f476) · [FB3Editor](https://github.com/Litres/FB3Editor/tree/a9a36f95a5a8b8eccb9e1fea3b14f8888fb87bf8) · [FB3Reader](https://github.com/Litres/FB3Reader/tree/eaedec1799f88797d1b3bb5bb0c8191f7aa6d9e0)

## Тестовый корпус

`tools/tests/test-fb3-package.ps1` создаёт небольшие OPC-пакеты с нестандартными путями, кодированием имён, отсутствующими ресурсами, неверными типами и повреждённым ZIP. Через `-ReferencePackage` можно передать официальные примеры, включая `Hardcore file structure.fb3` с кодированными именами, регистром и относительными целями, а также образцы `table_title_189446.fb3`, `same_img_cover_135705.fb3` и `move_id_from_a_to_block_136561.fb3`. Внешние книги используются из отдельной локальной копии репозитория FB3. [Официальный корпус](https://github.com/gribuser/FB3/tree/92bdc0d1fe89d9ac122ad342fd3c4cdc81a11c24)

В официальных `author_exists_193286.fb3`, `author_not_exists_193286.fb3` и `clipped_section_190994.fb3` есть связь на отсутствующую обложку. Чтение возвращает предупреждение об обложке и сохраняет доступ к тексту. `-ReferenceWithoutCover` проверяет именно этот результат. Связь на отсутствующую обязательную часть или иллюстрацию остаётся ошибкой.

## Проверка преобразования в FB2

`test-fb3-package.ps1 -ImportReference` проверяет, что преобразование завершается и полученный документ проходит штатную XSD FictionBook 2. В контролируемом пакете тест дополнительно проверяет поля описания, абзацы и форматирование, эпиграф, стихи, таблицу, сноску, ссылки и один общий бинарный ресурс для обложки и иллюстрации. Десять книг из примеров FB3 и набора `fb3_to_fb2` прошли проверку. Два `author_*_193286.fb3` ожидаемо отклонены с диагностикой отсутствующей связи на иллюстрацию. Этот случай отдельно проверяет `-ImportReferenceWithBrokenImage`.

Дополнительный набор состоит из девяти ознакомительных фрагментов Литрес в `.fb3`. Все девять преобразованы и проверены по XSD FB2. Среди них «Война и мир. Книга 1» с 241 ссылкой на примечания и иллюстрированный «Евгений Онегин» с 70 элементами `poem` и девятью вхождениями `img`. Проверка охватывает только содержимое фрагментов. В книгах с `<clipped>` преобразователь сообщает, что источник содержит только доступный фрагмент. [API фрагментов](https://docs.litres.ru/public/1247015.html) · [Война и мир](https://www.litres.ru/book/lev-tolstoy/voyna-i-mir-kniga-1-171746/) · [Евгений Онегин](https://www.litres.ru/book/aleksandr-pushkin/evgeniy-onegin-28737474/)

Фрагменты хранятся локально в `build/fb3-upstream/litres-trials`. Для повторной загрузки в документированном URL `https://partnersdnld.litres.ru/pub/t/<id>.fb3` использованы ID `152022`, `171746`, `171960`, `24779363`, `25452548`, `28070137`, `28737474`, `49592199`, `73529293`.

При преобразовании SVG растеризуется в PNG через LunaSVG с ограничением размеров. Старое стандартное объявление SVG 1.1 удаляется до разбора. Остальные DTD запрещены. Список, подпись таблицы и другие конструкции без прямого соответствия преобразуются с диагностикой. Если у обычной внутренней ссылки нет однозначной цели, конвертер сохраняет её видимое содержимое. Отсутствие целевой сноски или иллюстрации останавливает преобразование.

## Импорт через плагин и консоль

`ImportFB3.dll` реализует `IFBEPluginInfo2` и `IFBEImportPlugin2`, открывает системный диалог и отдаёт хосту валидированный поток FB2 в UTF-8. Адресный тест `test-fb3-import-plugin.ps1` активирует класс через `DllGetClassObject`, проверяет импорт из кириллического пути, отмену через токен и отмену выбора файла, отказ для повреждённого архива и сохранность источника. Плагины объявлены в штатном `Plugins/plugins.json`, названия команд берутся из локализованного каталога.

`ImportFB3Batch.exe` использует тот же преобразователь. Ключ `--recursive` сохраняет относительные подпапки. При совпадении имени выходной файл сохраняется, а этот вход отмечается как ошибка. Остальные книги обрабатываются дальше. Отчёты `.txt` и `.json` доступны через `--report`.

```powershell
ImportFB3Batch.exe .\Книги --output .\FB2 --recursive --report .\fb3-import
```

Коды завершения `0`, `1` и `2` означают соответственно успешную обработку, ошибки отдельных файлов и ошибку запуска или записи отчёта. `test-fb3-import-batch.ps1` проверяет одиночный и пакетный импорт, вложенные папки, смешанные результаты, отчёты, совпадение имён и исходные хеши.

Нормативные схемы и лицензия сохранены побайтно в `runtime/FB3Schemas`. `ValidatePackageSchemas` проверяет описание, текст и совпадение ID книги. Адресные тесты покрывают корректный пакет, неизвестный элемент и несовпадающие ID. Эта строгая проверка предназначена для создаваемых пакетов. Совместимость импортёра со старыми FB3 обеспечивают структурные проверки и валидация полученного FB2.

## Экспорт и проверка в обе стороны

`ExportFB3.dll` получает UTF-8 снимок через `IFBEDocumentSnapshot`. `ExportFB3Batch.exe` использует тот же преобразователь и принимает те же ключи, что и пакетный импорт. Ядро проверяет вход по XSD FB2, сопоставляет ссылки и изображения, записывает OPC во временный файл рядом с целью и открывает его повторно для проверки структуры и XSD FB3. После этой проверки и проверки отмены готовый файл перемещается на место назначения. Пакетная команда отказывает при совпадении имени.

На контролируемом документе проверены в обе стороны таблица, стихи, обложка, примечания, ссылки и метаданные. После FB3 → FB2 → FB3 → FB2 на 19 файлах проверены текст после нормализации пробелов, название, цели ссылок и байты изображений. Сценарий с неразрешимой ссылкой сохраняет прежний выходной файл. `test-fb3-import-plugin.ps1 -ExportPluginPath` отдельно проверяет экспорт из COM-снимка, отмену после начала преобразования и сохранность уже записанного файла.

К формату FB3 адаптируются сложные аннотации и содержимое примечаний. Различия в оформлении диагностируются. Издательский ISBN в произвольном формате хранится также в дополнительных метаданных. Временный файл и вывод ограничены лимитами загрузчика, входной FB2 ограничен 96 МиБ.

Для растровых ресурсов проверяются заявленный MIME и структура контейнера. Для PNG сверяются контрольные суммы блоков. Синтетический тест с повреждённым `IDAT` имеет корректную CRC на уровне ZIP и ожидаемо отклоняется на уровне изображения.

`test-fb3-editor-runtime.ps1` вызывает обе команды через редактор, меняет исходный XML импортированной книги, сохраняет FB2, открывает его повторно и проверяет текст после экспорта. Сценарий прошёл на собранном portable-пакете и в изолированном installed-профиле с файлами, извлечёнными из собранного NSIS. Хеши обоих DLL, пакетных программ, шести схем и лицензии в NSIS совпали со staging. Установка на систему тестом не выполнялась.

Проверки общего ZIP-распаковщика EPUB дали 21 PASS. Проверки меню прошли для `ru-RU` и `en-US`. Новые четыре бинарника прошли статическую проверку импортов WinAPI для Windows 7. Запуск на Windows 7 SP1 в этот набор не входит.
