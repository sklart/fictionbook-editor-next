# Карточки скриптов: формат, аудит и сопровождение

> Тип: Действующая инструкция. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Канонический источник

Основная карточка находится в самом `.js`; индекс и развёрнутые HTML/JSON-отчёты являются производными. Нормативные маркеры, кодировки, BOM, правила исключения блока из SHA и служебные команды описаны в [script-card-format.md](script-card-format.md).

Этот документ не заменяет спецификацию и не создаёт ещё один редактируемый каталог карточек.

## Разделять четыре результата

Инвентаризация подтверждает наличие файлов и полей. Эвристика находит кандидатов. Содержательная проверка сопоставляет утверждение с алгоритмом и зависимостями. Runtime проверяет конкретный сценарий настоящего JScript/MSHTML.

Отсутствие срабатывания эвристики не означает проверенную карточку. Понятный русский заголовок параметра не доказывает, что сам параметр влияет на заявленное поведение. Полнота списка внешних HTML/JS и возможность отказов проверяются отдельно.

## Правила правки

Сохраняйте исполняемый код, исходные комментарии, BOM, кодировку и окончания строк. В карточке допустимо уточнять назначение, авторство, параметры, зависимости и конкретные ограничения при наличии основания. Критический дефект алгоритма исправляется отдельным узким изменением с отдельной проверкой.

Не пересчитывайте code baseline ради исчезновения предупреждения. Не повышайте Undo-статус всего набора по результату одного представителя без анализа различий.

## Аудит и результаты

Инструмент направляет вывод `tools/audit-script-cards.py` в `out/reports/script-cards`. Генерируемые подробные `.json`, `.html`, `.md` больше не хранятся как действующая документация. Попытка направить генерацию внутрь `docs` отклоняется, чтобы не затереть ручные тексты и контрольные доказательства.

```powershell
python ./tools/audit-script-cards.py --output-dir ./out/reports/script-cards
```

Она по-прежнему проверяет baseline и подтверждённые proposals: историческое расхождение исходников может приводить к отказу. Нельзя обходить его слепым обновлением хешей. В этом пакете запуск полного аудита всех реальных скриптов не заявлен.

## Контрольные данные

Сохранены исходные JSON и Markdown, которые читаются тестами: baseline, reviewed proposals, классификация Undo, результаты примечаний и скрипта 64. Их точные пути и хеши формируются в [реестре доказательств](testing/evidence.md). Они не являются одноразовым мусором.

Большие промежуточные proposals без исполняемых потребителей сохраняются в архиве, а не удаляются по одному размеру. Производные подробные отчёты доступны в исходной Git-ревизии и могут быть пересозданы для подходящего входного состояния.

## Состояние незавершённой работы

Исторический исходный набор Undo включал 91 замечание; этап создания примечаний/комментариев исправил 12, оставив 79 исходных записей. Подробности и пределы проверки сохранены в [архиве карточек](archive/script-cards/README.md). Сводка не заменяет актуальный JSON по отдельному скрипту и не означает runtime-подтверждение всех аварийных ветвей.

Файл `scripting-api.md` сохраняется целиком: 88 публичных методов API 1.3.0, примеры и ещё не реализованные этапы не смешиваются с карточками комплектных скриптов. Статическая проверка списка методов приложена отдельно и не меняет контракт.
