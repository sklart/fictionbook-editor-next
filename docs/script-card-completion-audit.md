# Завершение текстовых исправлений и усиление стенда

Исправлены 12 фраз в usage/warnings шести карточек 02/04–06 и 03/04–06.
«После последней ссылки на примечание/комментарий» согласовано в единственном
числе. Короткий поиск аналогичных сочетаний в остальных карточках совпадений
не дал. Исполняемые байты, SHA, BOM, кодировки и окончания строк сохранены.
Точные изменения: [список](script-card-final-text-fixes.json).

Стенд проверяет полные имена строк имя=значение и ровно одно значение 1.
Пропуски, дубли и значение 10 отклоняются. Отрицательный пример special=0 при
replacement-special=1 отклоняется и C++-проверкой внутри FBE, и PowerShell.
Перед последним Run очищается история Undo после подготовки примера.
Проверяется ровно одна операция с названием скрипта, совпадение всего HTML тела
после Undo с исходным и после Redo с изменённым. После Undo история пуста.
Изоляция portable и восстановление буфера сохранены; cleanup выполняется даже
при ошибке восстановления буфера.

Реальный прогон старого алгоритма: обычная замена, каскад, дубли, единичные
Undo/Redo и отрицательные проверки парсера PASS. Спецсимволы справа по-прежнему
дают ожидаемый FAIL; он не скрыт. [Исходный результат](script64-before-safe-pairs.json).
В старом JScript повтор aA,bB,aC даёт CB: последнее значение занимает место
первого в перечислении. Цифровые ключи перечисляются по возрастанию перед
остальными: наблюдение 1A,2B,ay,bz (далее виден унаследованный член прототипа).

Сборка только FBE Release Win32 v143/14.44 со строгими предупреждениями прошла.
MSB8028 вызывался глобальным /p:IntDir, который наследует FBEContracts даже при
BuildProjectReferences=false. Без этого аргумента штатные разные каталоги
build/obj/fbe/Release и build/obj/contracts/Win32/Release не пересекаются;
MSB8028 не повторился. Изменять проекты или систему сборки не требуется:
для отдельного EXE достаточно OutDir, сохраняя штатный IntDir каждого проекта.
Сборка выполнена из рабочего дерева с посторонними изменениями; они в коммит
этого этапа не включаются. Полные E2E и verify-release не запускались.
