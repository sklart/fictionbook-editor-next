# UPX 5.3.1

Необязательный инструмент сборки обновлён с 5.3.0 до 5.3.1. Официальный архив [upx-5.3.1-win32.zip](https://github.com/upx/upx/releases/tag/v5.3.1) проверен по SHA-256 `2241AD04F82F801BA47AA58C3FE8A01E9EA3235389B1950122BF2C0E2585787F`; SHA-256 установленного `upx.exe` — `3E47C1F34EBE98CFDD3A3C0C1C94CF28FA299B41957B147A5289A0289D6EE7BF`. Файлы лицензии не изменились.

Проверены версия, упаковка тестового Win32 PE с `--exact`, проверка `-t`, запуск и совпадение SHA-256 после распаковки. Отдельный PE с подтверждённым Control Flow Guard отклонён без `--force`. Стандартная релизная сборка не использует UPX; политика упаковки не менялась.
