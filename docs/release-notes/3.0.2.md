# FictionBook Editor Next 3.0.2

FictionBook Editor Next 3.0.2 — небольшое сервисное обновление установщика после 3.0.1.

Главное изменение — переработанная интеграция `.fb2` с Windows. Вместо единого пункта «Системная интеграция» теперь можно независимо выбрать ассоциацию файлов, команду проверки FB2 и поддержку свойств/миниатюр в Проводнике.

Это особенно удобно, если FBE Next нужен как редактор, но для чтения `.fb2` уже используется другая программа.

## Главное в 3.0.2

* Системная интеграция `.fb2` разделена на **три независимые опции**.
* FBE Next можно установить, не меняя текущую программу для открытия `.fb2`.
* Команду **«Проверить FB2 на ошибки»** можно добавить отдельно.
* Свойства и миниатюры FB2 в Проводнике также можно подключить независимо.
* Все три компонента системной интеграции являются необязательными.
* Обновлены английские, русские и украинские тексты установщика.
* Документация дополнена объяснениями основных терминов FBE Next.

## Новая структура системной интеграции

До 3.0.2 различные функции интеграции FB2 с Windows были объединены в один компонент.

Теперь группа **«Системная интеграция»** содержит три отдельных пункта:

### Сделать FBE Next приложением для `.fb2`

Эта опция:

* связывает `.fb2` с FictionBook Editor Next;
* добавляет команды редактора для FB2;
* использует иконку FBE Next для соответствующей ассоциации.

Выбирать её следует, если пользователь действительно хочет использовать FBE Next как основное приложение для `.fb2`.

Если файлы уже открываются в другой программе и это поведение нужно сохранить, пункт можно просто оставить выключенным.

## «Проверить FB2 на ошибки»

Второй компонент независимо добавляет в контекстное меню `.fb2` команду:

**«Проверить FB2 на ошибки»**

Файл передаётся в FictionBook Validator (FBV).

Главное отличие 3.0.2: для установки этой команды **больше не требуется одновременно назначать FBE Next приложением для `.fb2`**.

Например, можно оставить для двойного щелчка:

* CoolReader;
* SumatraPDF;
* STDU Viewer;
* другую привычную программу,

но при этом иметь отдельную команду проверки FB2 через FBV.

Текущая программа по умолчанию и привычная иконка файла при таком сценарии сохраняются.

## Свойства и миниатюры в Проводнике

Третий независимый компонент включает интеграцию FB2 с Проводником Windows:

* чтение метаданных книги;
* дополнительные свойства файла;
* данные в панели сведений;
* миниатюры обложек.

При этом включение этого компонента само по себе **не назначает FBE Next программой для открытия `.fb2`**.

Таким образом, поддержку метаданных и обложек Проводника можно использовать независимо от выбранной читалки.

Для установки системных обработчиков Проводника могут потребоваться права администратора.

## Системная интеграция больше не обязательна

Все три новых компонента являются опциональными.

Это позволяет использовать FBE Next в нескольких вариантах.

### Только редактор

Можно установить FBE Next вообще без системной интеграции.

В этом случае установка не должна менять привычный сценарий работы с `.fb2` в Windows.

### Редактор + проверка FB2

Можно добавить только:

**«Проверить FB2 на ошибки»**

и оставить другую программу основной читалкой.

### Редактор + интеграция Проводника

Можно включить свойства и миниатюры FB2, не меняя программу для открытия книг.

### Полная интеграция

При необходимости можно выбрать все три компонента и использовать FBE Next как основную программу для `.fb2` вместе с FBV и расширенной поддержкой Проводника.

## Более понятные описания компонентов

Для новых вариантов интеграции добавлены отдельные пояснения непосредственно в установщике.

Например, для назначения FBE Next приложением для FB2 установщик явно предупреждает, что этот пункт меняет приложение и иконку `.fb2`, и рекомендует не выбирать его, если пользователь хочет сохранить существующую читалку.

Для команды проверки отдельно указано, что она не меняет приложение по умолчанию.

Для свойств и миниатюр поясняется, что компонент отвечает за метаданные, панель сведений и обложки в Проводнике.

## Локализация установщика

Новые компоненты и их пояснения добавлены сразу в три используемые на этом этапе локализации установщика:

* English;
* русский;
* українська.

Локализованы как названия отдельных компонентов, так и подробные описания их назначения.

## Обновлена документация

README дополнен разделом **«Коротко о терминах»**.

В нём простыми словами объясняются основные понятия, встречающиеся в документации и релизах FBE Next:

* FB2;
* XML;
* FBE и FBE Next;
* FBV;
* плагины;
* batch-конвертеры;
* portable-версия;
* ассоциации файлов;
* shell-интеграция;
* property handler;
* thumbnail provider;
* debug symbols;
* smoke- и regression-тесты;
* release-gate;

* WTL;
* Scintilla и Lexilla;
* PCRE2;
* Hunspell.

Это не влияет на работу программы, но делает README понятнее пользователям, которые не занимаются разработкой.

## Контроль новых вариантов установки

Для дальнейшего тестирования зафиксированы отдельные сценарии установки:

* без `.fb2`-интеграции;
* только с ассоциацией `.fb2`;
* только с командой проверки;
* только со свойствами и миниатюрами;
* с полным набором интеграции.

Это позволило в последующих версиях добавить автоматические проверки этих комбинаций.

## Что изменилось по сравнению с 3.0.1

3.0.2 почти не меняет сам редактор.

Основное отличие — **намного более аккуратное отношение к существующим настройкам Windows**.

Раньше системная интеграция рассматривалась как единый компонент.

Теперь пользователь самостоятельно решает:

* должна ли FBE Next открывать `.fb2`;
* нужна ли команда проверки через FBV;
* нужны ли свойства и миниатюры FB2 в Проводнике.

Поэтому 3.0.2 прежде всего стоит рассматривать как релиз **гибкой установки и интеграции с Windows**, а не как функциональное обновление редактора.
