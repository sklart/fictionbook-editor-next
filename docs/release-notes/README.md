# История выпусков и предварительных версий

> Тип: Навигация по опубликованным выпускам. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

## Роли источников

Опубликованный GitHub Release является действующим пользовательским описанием выпуска. Репозиторные файлы ниже — сохранённые исторические тексты или сопровождаемые конспекты. Сама разница объёма между ними не означает неисправность: текущий workflow специально сохраняет ручные правки опубликованного body.

При обновлении конспекта не переносите в старую версию функции, появившиеся позже. Исторические ограничения Windows 7 и отдельные старые пакеты сохраняются как факты о том выпуске, а не как инструкция к текущему.
