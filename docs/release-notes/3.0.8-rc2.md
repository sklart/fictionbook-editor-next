# FictionBook Editor Next 3.0.8 RC2

> Тип: Исторический конспект опубликованного RC. Документационная база: FBE Next 3.0.9, `master` / `1ad7c507d1ed`; сверка 19 октября 2026 года.

Это конспект второго предварительного выпуска 3.0.8. Источник подробностей и иллюстраций — [опубликованный Release v3.0.8-rc2](https://github.com/sklart/fictionbook-editor-next/releases/tag/v3.0.8-rc2). Публикация: 2 сентября 2026 года в 21:49 UTC, то есть 3 сентября 2026 года в 00:49 по Москве.

## Основные направления по сравнению с RC1

Выпуск сосредоточен на интерфейсе настроек, навигации по книге, строке состояния, файловых диалогах, системной интеграции, орфографии и надёжности сохранения. Это отдельный предварительный выпуск, а не обозначение стабильного 3.0.8.

## Примечания и навигация

В описании выпуска выделен предпросмотр примечаний: ограничение размера длинного текста, прокрутка, подбор размеров, наследование шрифта и основных цветов редактора. Popup создаётся вне редактируемого `fbw_body`, поэтому его показ не должен менять FB2 или создавать Undo-запись. Содержимое очищается перед показом.

## Настройки и повседневная работа

Изменения окон настроек, навигации, статусной информации и файловых диалогов направлены на более предсказуемую работу пользователя. При оценке конкретного дефекта сверяйте его с этим выпуском, а не приписывайте RC2 все последующие изменения 3.0.9.

## Пакеты и история

У этого тега встречались имена с `3.0.8-rc2` и позднее добавленные aliases с базовой `3.0.8`, в том числе `-win7-`. Они относятся к исторической публикации этого тега. По наличию такого имени нельзя делать вывод, что сейчас снова требуются две отдельные build-линии редактора.

Для актуальной сборки используйте [текущую инструкцию](../building.md), для сравнения со следующим стабильным выпуском — [3.0.9](3.0.9.md).
