# FictionBook Editor Next 3.0.12

Корректирующее обновление версии 3.0.11.

- Исправлена ошибка COM `80004005` при вставке форматированного текста из буфера обмена в поля вкладки «Описание».
- Исправлена обработка команд вставки в поля метаданных документа.
- Добавлены автоматизированные проверки вставки и сохранности содержимого книги.
- Необязательный сборочный инструмент UPX обновлён до версии 5.3.1.

Пользователям версии 3.0.11 рекомендуется обновиться.
