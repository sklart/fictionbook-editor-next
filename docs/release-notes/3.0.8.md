# FictionBook Editor Next 3.0.8 RC1

**3.0.8 RC1** — предварительный выпуск для тестирования следующей версии FictionBook Editor Next.

По сравнению с 3.0.7 основное внимание уделено portable-режиму и установщику, механизму обновлений, удобству редактирования таблиц, встроенным словарям и ExportHTML.

## Главное

* Установщик получил выбор между **обычной установкой** и **созданием portable-копии**.
* Для обычной установки можно выбрать установку **только для текущего пользователя** или **для всех пользователей компьютера**.
* Portable-режим стал значительно лучше изолирован от установленной версии: настройки, горячие клавиши, пользовательские слова, MRU, диагностика и другие изменяемые данные хранятся рядом с portable-копией.
* Встроенные плагины FBE Next больше не требуют обязательной COM-регистрации для обычной работы.
* В настройках появился выбор канала обновлений: **стабильные версии** или **Beta/RC**.
* Механизм обновлений получил корректное сравнение SemVer и отдельные stable/prerelease-каналы.
* Команды редактирования таблиц вынесены непосредственно на панель инструментов.
* Добавлены новые иконки и подсказки для операций с таблицами.
* Обновлены встроенные словари Hunspell: русский, украинский, английский и немецкий.
* Исправлен автономный ExportHTML и усилена проверка его шаблонов.
* Восстановлен явный выбор стандартных жанров FictionBook или расширенного набора LibRuSec.
* Обновлены libde265 до 1.1.1 и PlutoVG до 1.3.3.
* Существенно расширены проверки установщика, portable-пакета, обновлений и релизных артефактов.

# Установка и portable-режим

## Portable-копию теперь можно создать самим установщиком

В начале установки появился выбор типа развёртывания:

* **Установить FictionBook Editor Next**;
* **Создать портативную копию**.

Portable-режим теперь является полноценным вариантом развёртывания, а не просто отдельно подготовленным ZIP-архивом.

При выборе portable установщик:

* копирует необходимый runtime;
* создаёт `portable.ini`;
* создаёт локальный каталог `Data`;
* не предлагает ненужную системную интеграцию;
* не создаёт обычную запись установленной программы;
* не регистрирует shell-компоненты Windows.

Таким образом один и тот же установщик можно использовать и для обычной установки, и для подготовки переносной копии.

## Установка для текущего пользователя или для всех

Для обычной установки появился отдельный выбор области:

* **Только для текущего пользователя**;
* **Для всех пользователей компьютера**.

В первом случае программа устанавливается в пользовательский каталог и по возможности не требует повышения прав.

При выборе установки для всех пользователей используется системный каталог Program Files и при необходимости запрашиваются административные права.

Установщик также выявляет конфликт, если другая копия FBE Next уже установлена в противоположной области, вместо создания двух конфликтующих установок.

## Полноценная изоляция portable

Portable-версия теперь использует собственное локальное хранилище данных.

Изменяемые данные располагаются в каталоге `Data`, включая:

* настройки программы;
* горячие клавиши;
* пользовательские слова;
* список последних документов;
* выбранный язык;
* настройки панелей инструментов;
* пользовательские скрипты;
* diagnostic logs;
* crash diagnostics;
* recovery-файлы;
* временные и служебные данные.

Portable-копия больше не должна незаметно сохранять эти параметры в системный реестр и смешивать их с установленной FBE Next.

Это позволяет держать на одном компьютере несколько независимых portable-копий с разными настройками.

## Панели инструментов portable больше не пишутся в реестр

Отдельно исправлено сохранение состояния настраиваемых панелей инструментов.

Ранее часть состояния legacy Win32 toolbar могла обходить основной механизм настроек и попадать в реестр даже в portable-режиме.

В RC1 этот путь дополнительно изолирован.

## Системная интеграция отделена от portable

В portable-пакет не включаются компоненты, которые имеют смысл только при установке в Windows:

* FBShell;
* FBShell64;
* Property Handler;
* регистрационные scripts;
* shell MUI;
* схема дополнительных свойств Проводника.

Это делает portable-пакет чище и снижает риск случайного изменения системы.

# Плагины без обязательной COM-регистрации

Изменена загрузка встроенных плагинов:

* ImportEPUB;
* ExportHTML;
* ExportDOCX;
* ExportEPUB.

Для обычной работы FBE Next больше не требуется сначала регистрировать их DLL как глобальные COM-компоненты Windows.

Редактор может активировать поставляемые вместе с ним плагины локально.

Практические преимущества:

* portable-копия действительно может оставаться portable;
* плагины работают без записи CLSID в реестр;
* меньше вероятность конфликта разных установок;
* проще использовать несколько копий FBE Next;
* уменьшается необходимость запуска установки с повышенными правами.

Для старых внешних программ, которым исторически требуется зарегистрированный COM-сервер, в установщике сохраняется отдельный необязательный режим **Legacy COM compatibility**.

# Более безопасная деинсталляция

Переработана логика удаления системной интеграции.

Деинсталлятор теперь учитывает, действительно ли конкретная установка FBE Next владеет:

* ассоциацией FB2;
* ассоциацией FBD;
* командой проверки FBV;
* Property Handler;
* зарегистрированными плагинами.

Если после установки соответствующую регистрацию уже заняла другая программа или другая копия FBE Next, деинсталлятор не должен безусловно удалить чужую настройку.

Улучшена также миграция старого каталога shell-компонентов в `%ProgramData%`.

# Обновления

## Каналы обновлений

В **Настройки FBE Next → Обновления** появился выбор канала:

* **Стабильные версии (рекомендуется)**;
* **Предварительные версии (Beta / RC)**.

По умолчанию используется стабильный канал.

Пользователь, который хочет участвовать в тестировании, может включить получение предварительных выпусков непосредственно в программе.

## Отдельные stable и prerelease feeds

Для обновлений теперь используются два независимых манифеста:

* `update.xml` — стабильные версии;
* `update-prerelease.xml` — Beta/RC и последующие стабильные версии.

Публикация RC не изменяет обычный стабильный канал пользователей.

После выхода финальной версии prerelease-канал также получает её, поэтому пользователь RC может перейти на стабильный выпуск автоматически.

## Корректное сравнение SemVer

Сравнение версий переработано в соответствии с правилами Semantic Versioning.

Корректно различаются, например:

* `3.0.8-beta.1`;
* `3.0.8-rc.1`;
* `3.0.8-rc.2`;
* `3.0.8`.

Финальная `3.0.8` считается новее `3.0.8-rc.1`, а не равной или более старой.

Также добавлена строгая проверка некорректных номеров версий и release tags.

## «Что нового…»

Окно **«О программе»** показывает номер найденного обновления.

Добавлена команда **«Что нового…»**, открывающая страницу именно обнаруженного выпуска на GitHub.

Это особенно полезно для Beta/RC, где пользователь может сначала посмотреть изменения и известные особенности выпуска.

## Portable обновляется как portable

При проверке обновлений учитывается способ запуска программы.

Установленная FBE Next ориентируется на обычный setup.

Portable-копия не должна автоматически превращаться в установленную: для неё используется portable-артефакт соответствующего выпуска.

Таким образом обновление не должно затронуть локальный каталог `Data` и выбранную модель развёртывания.

# Редактирование таблиц

Основной механизм визуального редактирования таблиц и поддержка `rowspan`/`colspan` появились ранее, в 3.0.7.

В 3.0.8 RC1 эти возможности стали заметно доступнее из основного интерфейса.

## Команды таблиц на панели инструментов

На основную настраиваемую панель можно добавить команды:

* **Вставить строку выше**;
* **Вставить строку ниже**;
* **Удалить строку**;
* **Вставить столбец слева**;
* **Вставить столбец справа**;
* **Удалить столбец**;
* **Сделать ячейками заголовка**;
* **Сделать обычными ячейками**.

Раньше эти операции в основном выполнялись через меню и контекстное меню таблицы.

Теперь часто используемые команды доступны одним нажатием.

## Новые иконки

Для всех восьми команд подготовлен отдельный комплект графики.

Иконки переработаны в едином стиле и лучше передают направление операции:

* вставка строки;
* вставка столбца;
* удаление;
* преобразование TH/TD.

# Проверка орфографии

## Обновлены встроенные словари

В RC1 обновлены поставляемые Hunspell-словари:

* русский;
* украинский;
* английский;
* немецкий.

Для каждого словаря сохранены сведения об источнике и лицензии.

## Проверка совместимости словарей

Добавлены отдельные автоматические тесты, которые действительно загружают `.aff` и `.dic` через Hunspell.

Проверяется не только наличие файлов, но и базовая работа словаря с реальными словами.

Это снижает вероятность выпустить обновлённый словарь, который формально лежит в пакете, но не загружается движком проверки орфографии.

# ExportHTML

Автономный режим ExportHTML появился в 3.0.7. В RC1 исправлена его работа в реальном production-пути.

## Исправлены изображения

Усилена обработка изображений в автономном HTML.

Проверяется полный экспорт реальной книги с иллюстрациями, а не только отдельная XSLT-трансформация.

Изображения должны корректно:

* извлекаться из `<binary>`;
* преобразовываться в необходимые `data:` URI в standalone-режиме;
* сохраняться рядом с HTML в обычном режиме.

## Штатные шаблоны

Приведён в порядок механизм выбора встроенного `html.xsl`.

ExportHTML теперь надёжнее определяет штатный шаблон независимо от текущего каталога запуска.

Добавлены проверки происхождения и комплектности поставляемого XSL.

Это уменьшает риск ситуации, когда экспорт использует случайный или устаревший `html.xsl` из другого каталога.

# Жанры FictionBook

В настройках снова доступен явный выбор используемого набора жанров:

* стандартный список **FictionBook**;
* расширенный список **LibRuSec**.

Это возвращает пользователю возможность сознательно выбирать между строгим стандартным набором и более широким каталогом жанров.

Выбор сохраняется в настройках и учитывается как в обычной, так и в portable-конфигурации.

# Графические зависимости

Обновлены отдельные библиотеки, используемые при импорте изображений и EPUB:

* **libde265 1.1.1** — декодирование HEVC для HEIC/HEIF;
* **PlutoVG 1.3.3** — растровый backend LunaSVG.

Эти обновления в первую очередь связаны с исправлениями и поддерживаемостью графического стека.

# Надёжность и тестирование

Для 3.0.8 заметно переработан release-gate.

## Portable

Автоматически проверяются:

* наличие `portable.ini`;
* структура `Data`;
* отсутствие системных shell-компонентов;
* отсутствие нежелательной COM-регистрации;
* отсутствие записи portable-настроек в реестр;
* сохранение GUI-состояния;
* настройки панели инструментов;
* hotkeys;
* пользовательские слова;
* MRU;
* локализация;
* несколько независимых portable-копий.

Для тегированных выпусков выполняется не только быстрый smoke, но и полный сценарий изменения и повторного чтения portable-состояния.

## Установщик

Проверяются:

* установка только для текущего пользователя;
* установка для всех пользователей;
* создание portable-копии;
* запрос UAC только при необходимости;
* конфликт двух областей установки;
* корректность ассоциаций;
* безопасная деинсталляция;
* отсутствие удаления чужих регистрационных данных.

## Плагины

Отдельно проверяется локальная активация встроенных плагинов без регистрации их COM-классов в Windows.

## Обновления

Проверяются:

* stable/prerelease feeds;
* SemVer;
* malformed version strings;
* release tag;
* URL артефактов;
* SHA-256;
* выбор setup или portable ZIP;
* переход RC → stable.

## ExportHTML и словари

Production-тестами дополнительно охвачены:

* экспорт изображений;
* standalone HTML;
* выбор XSL-шаблона;
* реальные Hunspell-словари.

# Что проверить в RC1

При тестировании 3.0.8 RC1 особенно полезно проверить:

1. Создание portable-копии непосредственно из установщика.
2. Запуск двух portable-копий из разных каталогов и независимость их настроек.
3. Отсутствие изменений системного реестра после обычной работы portable-версии.
4. Работу ExportHTML, ExportDOCX, ExportEPUB и ImportEPUB без предварительной COM-регистрации.
5. Установку «Только для текущего пользователя».
6. Установку «Для всех пользователей».
7. Корректное удаление FBE Next без повреждения чужих ассоциаций FB2/FBD.
8. Переключение канала Stable ↔ Beta/RC.
9. Проверку обновлений из portable-копии.
10. Новые кнопки операций с таблицами, включая disabled-состояние и Undo/Redo.
11. Русскую, украинскую, английскую и немецкую проверку орфографии.
12. ExportHTML с несколькими изображениями в обычном и автономном режимах.
13. Переключение стандартных жанров FictionBook и LibRuSec.

# Что скачивать

Для тестирования предварительного выпуска доступны обычные варианты сборки:

### Windows 8.1 / 10 / 11

* `FictionBookEditorNext-3.0.8-win32-setup.exe` — установщик с выбором обычной или portable-установки;
* `FictionBookEditorNext-3.0.8-win32-portable.zip` — готовая portable-сборка.

### Windows 7 SP1

* `FictionBookEditorNext-3.0.8-win7-win32-setup.exe`;
* `FictionBookEditorNext-3.0.8-win7-win32-portable.zip`.

RC1 является предварительным выпуском. Для обычных пользователей рекомендуется оставаться на стабильном канале, а 3.0.8 RC1 использовать для тестирования изменений перед финальным выпуском.
