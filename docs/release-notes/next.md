# Следующий выпуск после 3.0.9 — проект описания

Номер версии и тег не выбраны. Этот документ не означает публикацию релиза или update manifest.

## Изменения после v3.0.9

- Исправлены тёмная тема, значки и стартовая панель, Tooltips, настройки EPUB/DOCX, повреждение меню при смене темы/обновлении скриптов и оформление системных файловых диалогов (#64).
- Усилены закрытие и замена документа, отсоединение COM-ресурсов, откат при ошибке создания и безопасное первое сохранение импортированной книги.
- Доступен scripting API 1.5.0, 104 метода. Принятый объём #45 завершён; физическая DPI/locale/Windows-матрица выделена в #66.
- Исправлены конкурентная атомарная запись шаблонов поиска и нестабильная подготовка теста HTML-транзакций без ослабления проверок сохранности данных.
- Исправлены проверки FBD/File Close и условия загрузки снимков Regex Help; локальный FULL использует обязательные lifecycle/API-матрицы CI и явно контролирует внешнюю проверку реального OLE Clipboard.

## Ограничения и приёмка

- Windows 10 22H2: POST-RELEASE, пользователь проверяет опубликованную версию; ручной PASS до публикации не требуется.
- Windows 7 SP1 runtime: NOT RUN при отсутствии реальной среды. Совместимость целевых API сохраняется; PE-import gate не заменяет запуск на Windows 7.
- High Contrast, системная Dark и ручная физическая DPI/locale-матрица #66: NOT RUN/DEFERRED. Контролируемые DPI-сообщения и выбор языка приложения не считаются сменой системного DPI/локали.
- Единичный прежний сбой TreeView повторно не воспроизведён; причина неизвестна. Диагностические ограничения MSHTML Split/Undo сохраняются явно отдельно от функциональных тестов.
- #41, #43, #44, #49 и #59 остаются отдельными задачами. Полная матрица внешних приложений, больших книг и ручного GUI не заявляется пройденной. Подтверждённая потеря данных или вылет в базовом сценарии блокирует выпуск.

Перед публикацией необходимо приложить результат полного автоматического gate и успешного Build (validate/build/package) для одного итогового SHA, контрольные суммы setup/portable/symbols и проверенный candidate manifest. До такой записи готовность к релизу не объявляется. Кандидат manifest не публикуется автоматически в рамках этой приёмки.
