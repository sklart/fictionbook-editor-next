# Следующий выпуск

## FictionBook 3

Файлы `.fb3` можно импортировать через меню «Файл → Импорт» и редактировать как обычные документы FictionBook 2. Команда «Файл → Экспорт → FictionBook 3 (.fb3)» сохраняет текущую книгу в FB3.

Для файлов и папок доступны `ImportFB3Batch.exe` и `ExportFB3Batch.exe`. Пакетные утилиты поддерживают рекурсивную обработку, отчёты TXT и JSON и защищают существующие выходные файлы. [Команды, проверки и ограничения](../architecture/fb3.md)
