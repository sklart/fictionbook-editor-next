# FictionBook Editor Next 3.0.0

FictionBook Editor Next 3.0.0 — первый релиз новой ветки развития FictionBook Editor.

Это **не переписывание редактора с нуля**. В основе остаётся привычный FictionBook Editor со знакомой моделью редактирования FB2, встроенными скриптами и существующей логикой работы с книгой.

Главная задача версии 3.0.0 — модернизировать техническую основу проекта, сохранив привычный рабочий процесс.

В результате обновлены сборка и установщик, интеграция с Windows, проверка FB2, механизм регулярных выражений и редактор XML-кода, добавлены новые плагины импорта/экспорта, batch-конвертеры и современная диагностика.

## Главное в 3.0.0

* Проект получил новое имя **FictionBook Editor Next**.
* Начата новая ветка версий с номера **3.0.0**.
* Добавлен экспорт FB2 в **DOCX**.
* Добавлен экспорт FB2 в **EPUB 2 / EPUB 3**.
* Добавлен импорт **EPUB → FB2**.
* Добавлены batch-конвертеры для пакетной обработки.
* Полностью модернизирована интеграция `.fb2` с Проводником Windows.
* Добавлены свойства FB2 и миниатюры встроенных обложек.
* FictionBook Validator возвращён в исходники проекта и собирается вместе с FBE Next.
* Legacy PCRE заменён на **PCRE2**.
* Старый SciLexer заменён на **Scintilla + Lexilla**.
* Обновлён Hunspell.
* Улучшена защита от потери данных при сохранении read-only файлов.
* Добавлена современная система сборки, portable-пакет, debug symbols и автоматическая проверка релиза.
* Улучшена устойчивость ExportEPUB к нестандартным и повреждённым книгам.
* Накопленные после старой ветки изменения встроенных скриптов вошли в новый релиз.

# Улучшена надёжность ExportEPUB

Перед выпуском 3.0.0 ExportEPUB получил отдельный большой набор исправлений.

## Более корректный EPUB 2 / XHTML 1.1

Исправляется структура генерируемого XHTML.

В частности:

* текстовые фрагменты непосредственно внутри некоторых блочных элементов преобразуются в корректные абзацы;
* для `cite` и `epigraph` формируется допустимая блочная структура;
* блочные элементы не помещаются внутрь ссылок там, где это нарушало XHTML;
* структура EPUB 2 лучше соответствует XHTML 1.1.

## Обработка ссылок

Локальные ссылки вида:

`file://...`

из исходного FB2 больше не должны случайно попадать в готовую электронную книгу.

HTTP/HTTPS-ссылки с обратными слэшами нормализуются.

## Более безопасная работа с binary

Старый механизм декодирования встроенных изображений через MSXML `bin.base64` заменён собственным base64-декодером.

Он корректно обрабатывает:

* пробелы;
* переносы строк;
* стандартные FB2 binary.

Повреждённый неиспользуемый binary больше не должен автоматически срывать экспорт всей книги.

## Улучшена диагностика

В пакетном ExportEPUB фиксируются стадии обработки, например:

* загрузка FB2;
* настройка XML namespaces;
* построение модели EPUB;
* применение параметров экспорта;
* preflight;
* запись EPUB;
* сохранение диагностического журнала.

Это позволяет значительно быстрее определить место возникновения ошибки.

# Улучшено безопасное сохранение read-only файлов

Исправлен потенциально опасный сценарий работы с FB2, имеющим атрибут:

**«Только чтение»**

При обычной команде сохранения FBE теперь заранее обнаруживает этот статус и предупреждает пользователя.

Вместо неочевидной ошибки предлагается сохранить документ через:

**«Сохранить как…»**

Если пользователь отказывается от сохранения, документ остаётся помеченным как изменённый.

Это уменьшает риск ошибочно решить, что внесённые изменения уже сохранены.

# Исправлено открытие относительных путей

Исправлен запуск FBE с относительным путём к FB2 из командной строки.

Перед загрузкой документа такой путь преобразуется в полный.

Один и тот же нормализованный путь используется для:

* загрузки файла;
* проверки его возраста;
* списка последних документов;
* резервного открытия в режиме исходного XML.

Это устраняет несколько сценариев, где файл существовал, но FBE не мог корректно обработать переданный относительный путь.

---

# PCRE заменён на PCRE2

Устаревший движок регулярных выражений **PCRE** заменён на современный:

**PCRE2**

Legacy `pcre.dll` больше не является частью основного runtime FBE Next.

Для пользователя это означает более современную и поддерживаемую основу механизмов регулярного поиска и замены.

При переходе были добавлены отдельные regression-наборы для проверки совместимости существующих регулярных выражений FBE.

---

# SciLexer заменён на Scintilla + Lexilla

Историческая монолитная библиотека:

`SciLexer.dll`

заменена современной архитектурой:

* **Scintilla** — редактор текста;
* **Lexilla** — лексеры и подсветка синтаксиса.

Именно эта связка используется в режиме просмотра и редактирования исходного XML.

Это упрощает обновление текстового редактора независимо от набора лексеров и создаёт более современную основу для дальнейшего развития режима **Код**.

Это улучшает совместимость с современными словарями и упрощает дальнейшие обновления spellchecker-контуров.

# Что изменилось по сравнению со старой веткой

3.0.0 — это прежде всего переход от исторически развивавшегося FictionBook Editor к поддерживаемому **FictionBook Editor Next**.

Ключевые направления перехода:

### Редактор

Сохраняется привычная работа с FB2 и существующая модель интерфейса.

### Импорт и экспорт

Добавляются DOCX, EPUB и ImportEPUB с пакетными конвертерами.

### Проводник Windows

Старый shell-код заменяется современной системой свойств и миниатюр.

### Проверка FB2

FBV возвращается из готового бинарника в исходный код проекта.

### Регулярные выражения

PCRE заменяется PCRE2.

### Редактор XML

SciLexer заменяется Scintilla + Lexilla.

### Проверка орфографии

Обновляется Hunspell.

### Установка и выпуск

Появляются современный установщик, portable-пакет, автоматическая сборка, release-gate, debug symbols и SHA-256.

### Надёжность

Исправляется работа с read-only файлами, относительными путями и рядом старых проблем, обнаруженных статическим анализом.

Именно поэтому переход на версию **3.0.0** соответствует масштабу изменений: это новая поддерживаемая ветка существующего FictionBook Editor, а не просто очередная небольшая сборка старой линии.
