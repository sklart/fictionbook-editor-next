### Главное

- Это релиз FictionBook Editor Next с завершённым базовым контуром локализации интерфейса.
- Язык FBE теперь согласован с FBV, командами импорта/экспорта и их окнами настроек через единые языковые пакеты.
- Шаблоны новых FB2 намеренно не менялись: их локализация будет отдельной задачей, чтобы не смешивать изменения интерфейса и содержимого документов.
- Иконки FBE Next обновлены: они используют новый прозрачный вариант без белого фона и лучше выглядят на цветных темах Проводника и панели задач.

### Что изменилось для пользователя

- В установщике доступны те же 12 языков, что и в программе: английский, русский, украинский, немецкий, французский, испанский, итальянский, польский, португальский, нидерландский, чешский и болгарский. Английский, русский и украинский выбраны по умолчанию; остальные можно включить при установке.
- Страницы выбора компонентов и завершения установки получили стартовые переводы для дополнительных европейских языков. Редкие технические сообщения пока могут отображаться по-английски: это безопасный запасной вариант до вычитки переводчиками.
- Исправлена финальная страница установщика: русский текст и подпись запуска FBE Next больше не должны отображаться искажёнными символами или обрезаться.
- В настройках FBE показываются только реально установленные языки. Если каталог языка удалить вручную, этот язык исчезнет из списка при следующем открытии настроек.
- При смене языка сразу обновляются главное меню, панели, команды импорта/экспорта, подсказки и основные окна FBE. Окна плагинов используют новый язык при следующем открытии.
- Исправлены зависание, рост потребления памяти, наложение подписей и риск аварийного завершения после нескольких смен языка.
- Языковые JSON-файлы и ресурсные DLL теперь находятся только внутри `Lang/<язык>`, поэтому в каталоге программы больше не остаются пустые старые папки локалей.
- Обновлены Scintilla до 5.6.4 и Lexilla до 5.5.1: в редакторный компонент и подсветку синтаксиса вошли накопленные исправления их разработчиков.
- FBE Next больше не использует настройки, словари, историю и регистрации старого FictionBook Editor: они хранятся отдельно. Это позволяет безопасно держать обе программы на одном компьютере. После обновления рекомендуем один раз проверить язык интерфейса, шрифты, пути к словарям, набор скриптов и другие личные настройки: они не переносятся автоматически из старого профиля.
- В режиме просмотра исходного XML снова видна XML-декларация документа, а файл, сохранённый через «Сохранить как», корректно попадает в список последних документов.

### Что скачивать

- `FictionBookEditorNext-3.0.5-win32-setup.exe` — основной установщик для Windows 8.1 / 10 / 11. Рекомендуется большинству пользователей.
- `FictionBookEditorNext-3.0.5-win32-portable.zip` — основная portable-версия для Windows 8.1 / 10 / 11.
- `FictionBookEditorNext-3.0.5-win7-win32-setup.exe` — установщик для Windows 7 SP1. Выбирайте его на Windows 7 вместо основного установщика.
- `FictionBookEditorNext-3.0.5-win7-win32-portable.zip` — portable-версия для Windows 7 SP1. Скачивайте её, если обычный пакет не запускается на Windows 7.
- `FictionBookEditorNext-3.0.5-win32-symbols.zip` — debug-символы для диагностики основной сборки.
- `FictionBookEditorNext-3.0.5-win7-win32-symbols.zip` — debug-символы для диагностики Win7-сборки.
- `SHA256SUMS.txt` — контрольные суммы файлов релиза.
