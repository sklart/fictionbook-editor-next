### Главное

- Это patch-релиз FictionBook Editor Next с улучшениями повседневной работы в режимах «Тело» и «Код», настройках и локализации.
- Для Windows 7 SP1, как и прежде, публикуется отдельная совместимая сборка.

### Что изменилось для пользователя

- При переключении между «Тело» и «Код» FBE переносит выделение в обоих направлениях, прокручивает Source к нужному месту и безопасно обрабатывает диапазоны через абзацы и XML-разметку. Требуется дополнительное ручное тестирование на разнообразных FB2.
- Все страницы окна настроек используют единый шрифт и размер, соответствующие вкладке «Слова».
- Исправлены повреждённые русские и украинские строки: подсказки панели инструментов и названия команд больше не отображаются вопросительными знаками.
- Вкладка «Настройки FBE Next» позволяет включать и отключать создание резервной копии `.bak` при перезаписи книги. Безопасное атомарное сохранение сохраняется в любом режиме.
- Локализованные resource DLL теперь располагаются только в каталогах `Lang\ru-RU` и `Lang\uk-UA`.
- Документация API пользовательских JavaScript-скриптов дополнена описаниями, примерами и оглавлением.
- В ExportDOCX исправлено предупреждение PVS-Studio при обработке заголовков сносок со знаком «№».
- Экспорт в HTML, DOCX и EPUB корректно устанавливается без прав администратора; сообщения установщика на русском больше не должны отображаться повреждённым текстом.
- На странице выбора компонентов увеличено поле описания; длинные пояснения сокращены и больше не должны обрезаться.

- `FictionBookEditorNext-3.0.6-win7-win32-setup.exe` — установщик для Windows 7 SP1.
- `FictionBookEditorNext-3.0.6-win7-win32-portable.zip` — portable-версия для Windows 7 SP1.
- `FictionBookEditorNext-3.0.6-win32-symbols.zip` и `FictionBookEditorNext-3.0.6-win7-win32-symbols.zip` — debug-символы.
