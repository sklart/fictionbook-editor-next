# FictionBook Editor Next 3.0.11 — проект описания

В новом профиле импорт EPUB включает обработку разделителей, создание титула из метаданных, единые имена изображений, отдельное имя обложки и нумерацию примечаний. Экспорт EPUB сохраняет иллюстрацию в тексте при отсутствии обложки. HTML выводит три уровня оглавления. DOCX добавляет оглавление, берёт язык из FB2 и оставляет создание отчёта по выбору пользователя. Сохранённые значения отдельных настроек имеют приоритет.

**Черновик для внутреннего тестирования. Версия не выпущена; состав и результаты проверок уточняются.**

## Изменения после 3.0.10

- В редакторе доработаны обработка вставки, история отдельных операций, переходы Body/Source, поиск и массовая замена, сохранение и работа с вложениями. При создании цитаты поддержано включение уже оформленного стихотворения; неподдерживаемые границы выделения отклоняются с предупреждением.
- Доработаны пользовательские панели и дерево скриптов, настройка размеров значков, отображение и прокрутка карточек, сохранение идентификаторов и настроек.
- В импорте EPUB улучшены распознавание примечаний, внутренние и навигационные ссылки, сохранение библиографических записей, вложенные списки, структура текста, таблицы и изображения, а также передача отдельных конструкций MathML. Исправлены ошибки конвертации и замедление обработки пробелов и ссылок. Абсолютная точность преобразования не предполагается; подробности — в [отчёте о проверке корпуса](../epub-import-final-acceptance-3.0.11.md).
- Расширены настройки цветовых схем интерфейса и исправлено отображение элементов в светлых и тёмных темах. Для вкладки «Описание» восстанавливается прежняя компоновка 3.0.10; экспериментальные Modern и обновлённый Classic в этот этап не входят.
- Обновлены Scintilla 5.6.9, Lexilla 5.5.5, libarchive 3.8.11, libaom 3.15.3 и сборочный UPX 5.3.0. Стандартная сборка UPX не использует.

## Известные ограничения и незавершённые проверки

- **Split/Undo — KNOWN FAILURE / DEFERRED.** Ранее в отдельных сборках наблюдалось неполное восстановление структуры. На промежуточной сборке текущая матрица 16/16 прошла; расхождение с прежними наблюдениями не объяснено и не доказывает исправления.
- Исправлена загрузка скриптов в MSHTML. В Windows-проверке пустой запуск сохранил книгу чистой. Отмена удаления вложений и запуск статистики сохранили книгу и историю во всех девяти проверенных сочетаниях операции и состояния.
- В адресной проверке Recovery после замены вложения скриптом сохранил ожидаемые байты и ссылку на вложение. В корпусе EPUB семь исходных файлов не содержат обязательных ресурсов; часть сравнений неоднозначна, а содержательное сравнение крупных книг ограничено размером.
- Результаты штатного релизного цикла и проверки готовых пакетов записываются отдельно для итоговой ревизии. Исследование больших книг и ручная проверка Windows 7 исключены из этого этапа.
