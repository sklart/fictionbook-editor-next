# FictionBook Editor Next 3.0.4

FictionBook Editor Next 3.0.4 — обновление совместимости и релизной инфраструктуры, главным изменением которого стало разделение поставки на **основную Modern-сборку** и отдельную **Windows 7-compatible сборку**.

Версия также исправляет несколько проблем совместимости плагинов на чистых системах, улучшает работу ExportHTML и ExportEPUB и закладывает основу новой системы локализации FBE Next.

## Главное в 3.0.4

* Появилась отдельная сборка **для Windows 7 SP1**.
* Основная сборка остаётся предназначенной для Windows 8.1 / 10 / 11.
* Scintilla адаптирована так, чтобы Win7-сборка не импортировала отсутствующую в Windows 7 функцию `GetSystemTimePreciseAsFileTime`.
* Аналогичная проблема устранена в ExportEPUB.
* Улучшена регистрация ExportHTML на чистых системах.
* Усилена проверка совместимости плагинов и batch-конвертеров с Windows 7.
* Начата подготовка единой системы локализации FBE, FBV и плагинов.
* В FBV вынесены из кода основные пользовательские сообщения для дальнейшей полноценной локализации.

## Отдельные Modern и Windows 7 сборки

Начиная с 3.0.4 один и тот же универсальный пакет больше не используется для всех поддерживаемых Windows.

Релиз разделён на два профиля.

### Modern

Основная и рекомендуемая сборка для:

* Windows 8.1;
* Windows 10;
* Windows 11.

Она использует обычный современный набор настроек сборки и является рекомендуемым вариантом для большинства пользователей.

### Windows 7 compatible

Для Windows 7 SP1 теперь выпускаются отдельные:

* установщик;
* portable-архив;
* архив отладочных символов.

Эта сборка специально формируется с более осторожными настройками совместимости и проверяется на отсутствие критических импортов WinAPI, появившихся только в Windows 8 и более новых системах.

Win7-установщик также явно помечается как **Windows 7 compatible**, чтобы его было проще отличить от основной версии.

## Исправлена работа Scintilla на Windows 7

Одной из основных причин появления отдельной Win7-сборки стала современная версия Scintilla.

При обычной сборке `Scintilla.dll` могла получить прямую зависимость от:

`GetSystemTimePreciseAsFileTime`

Эта функция появилась только начиная с Windows 8.

В результате на Windows 7 библиотека могла вообще не загрузиться, а вместе с ней становился недоступен режим редактирования исходного XML.

Для Win7-профиля Scintilla теперь собирается с целевой версией Windows 7:

`WINVER / _WIN32_WINNT = 0x0601`

В чувствительном к совместимости коде измерения времени используется совместимый механизм на основе `QueryPerformanceCounter`.

Это позволяет избежать прямого импорта `GetSystemTimePreciseAsFileTime` и сохранить работу редактора исходного XML на Windows 7.

## ExportEPUB и Windows 7

Аналогичная проблема обнаружена в ExportEPUB.

Для формирования временных меток EPUB плагин также мог получить зависимость от:

`GetSystemTimePreciseAsFileTime`

В Win7-сборке используется совместимый `GetSystemTime`.

Для пользователя процесс экспорта не меняется — изменение касается только внутреннего получения времени.

Таким образом, ExportEPUB больше не должен отказываться загружаться на Windows 7 только из-за отсутствия этой функции WinAPI.

## Улучшена регистрация ExportHTML

Исправлена COM-регистрация `ExportHTML.dll`.

Ранее `DllRegisterServer` дополнительно пытался зарегистрировать type library, хотя для работы ExportHTML внутри FBE достаточно регистрации COM-класса самого плагина.

На некоторых чистых системах лишний этап регистрации type library мог завершиться ошибкой.

В результате:

* установка могла выглядеть успешной;
* но ExportHTML не появлялся в меню экспорта FBE.

В 3.0.4 этот лишний шаг убран, а схема регистрации ExportHTML приведена к той же модели, которая используется более современными плагинами FBE Next.

## Улучшена автономность плагинов

Для релизных GUI-плагинов и batch-конвертеров добавлена проверка использования статического CRT (`/MT`).

Это особенно важно для:

* portable-версии;
* чистой Windows 7;
* компьютеров без установленного подходящего Visual C++ Runtime.

Цель — уменьшить вероятность ситуации, когда основная программа запускается, а отдельный плагин или конвертер отсутствует в интерфейсе только из-за недостающей runtime-библиотеки Microsoft.

При этом сама Windows 7 всё равно должна быть нормально обновлена.

## Требования Windows 7

Совместимая сборка рассчитана на:

**Windows 7 SP1 с актуальными системными обновлениями.**

Для современной программной среды Windows 7 по-прежнему могут понадобиться:

* Universal CRT;
* системное обновление KB2999226;
* актуальный Microsoft Visual C++ Redistributable.

Отдельная Win7-сборка устраняет прямые зависимости FBE Next от ряда функций Windows 8+, но не заменяет необходимые системные обновления самой Windows 7.

## Автоматическая проверка Win7-совместимости

В релизный процесс добавлена отдельная проверка импортов исполняемых файлов и DLL.

Она выявляет прямые зависимости от функций, отсутствующих в Windows 7, в том числе:

* `GetSystemTimePreciseAsFileTime`;
* семейство `PathCch*`.

Это позволяет обнаружить подобную проблему ещё до публикации релиза, а не после сообщения пользователя о том, что DLL или программа не запускается.

Modern- и Win7-сборки также получили раздельные профили проверки runtime-файлов.

## Начало новой системы локализации

3.0.4 также стал первым этапом большой переработки системы локализации, которая получила дальнейшее развитие в 3.0.5.

Важно: **в 3.0.4 эта работа ещё не означает полноценную поддержку всех новых языков в интерфейсе и установщике**. Здесь в основном создаётся инфраструктура для последующего перехода.

Подготовлены стабильные каталоги переводимых строк для:

* FBE;
* FBV;
* ExportHTML;
* ExportDOCX;
* ExportEPUB;
* ImportEPUB.

В качестве основного будущего внешнего формата локализации выбран JSON.

Целевая структура предполагает языковые каталоги вида:

`Lang\en-US`

`Lang\ru-RU`

`Lang\uk-UA`

и т. д.

При отсутствии внешнего перевода предусмотрена схема fallback к английскому и затем к встроенной строке приложения.

## Подготовка к Weblate

Создана основа для последующего подключения проекта к Weblate или другому веб-сервису переводов.

Вместо непосредственного редактирования переводчиками Win32 `.rc`-файлов предполагается использовать текстовые записи со стабильными идентификаторами.

Это позволяет отделить:

* перевод текста;
* координаты элементов диалогов;
* внутреннюю структуру Win32-ресурсов.

Также добавлен экспорт переводов в раздельные JSON-файлы, пригодные для дальнейшей передачи в систему коллективного перевода.

## Начата локализация FictionBook Validator

Основные пользовательские строки FBV начали переноситься из жёстко заданного C++-кода в ресурсы.

Это касается, в частности:

* статуса завершения проверки;
* кнопок `Stop`, `Revalidate`, `Exit`;
* названия колонки;
* сообщения об отсутствии ошибок;
* сообщений SAX/XML;
* основных сообщений об ошибках.

Для целевых языков подготовлены соответствующие ресурсные строки.

Это первый этап последующей интеграции FBV в общую языковую систему FBE Next.

## Подготовка локализации плагинов

Создан отдельный каталог переводимых строк для:

* ExportHTML;
* ExportDOCX;
* ExportEPUB;
* ImportEPUB.

В нём используются стабильные текстовые ключи вместо привязки переводов непосредственно к расположению элементов в `.rc`-диалогах.

Для русского и украинского подготовлены основные переводы, а для будущих европейских локализаций — стартовые варианты.

Полноценная runtime-интеграция этих каталогов развивается в следующих версиях.

## Проверка релизных пакетов

Из-за появления двух вариантов сборки существенно усилена автоматическая проверка релиза.

Отдельно контролируются:

* Modern-сборка;
* Win7-сборка;
* setup-пакеты;
* portable-пакеты;
* debug symbols;
* runtime DLL;
* WinAPI-импорты;
* статический CRT плагинов;
* регистрация ImportEPUB;
* структура будущей локализации.

Это внутренние изменения, но они уменьшают вероятность публикации пакета, в котором отсутствует нужный DLL, плагин или Win7-совместимый компонент.

## Что изменилось по сравнению с 3.0.3

Главное отличие 3.0.4 — **Windows 7 из режима «ожидаемой совместимости» переведена в отдельный контролируемый релизный профиль**.

Вместо одной сборки теперь публикуются:

* современная версия для Windows 8.1 / 10 / 11;
* специальная версия для Windows 7 SP1.

Дополнительно исправлены проблемы совместимости Scintilla и ExportEPUB, улучшена регистрация ExportHTML и заложена инфраструктура новой системы локализации.

То есть 3.0.4 — прежде всего релиз **совместимости и подготовки архитектуры**, а не версия с большим количеством новых функций редактора.
