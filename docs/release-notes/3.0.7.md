### Статус выпуска

- Это предварительный выпуск для ручного и общественного тестирования. Он не участвует в автоматическом обновлении стабильной версии 3.0.6.

### Исправления и улучшения

- Исправлена COM-ошибка при переходе в режим «Код» у книг с иллюстрациями: сериализация base64-содержимого `binary` совместима с MSXML6.
- Диагностический журнал включается из меню «Сервис» или переменной `FBE_NEXT_TRACE`; он помогает исследовать переходы между «Телом», «Описанием» и «Кодом», а также ошибки COM, документов и скриптов.
- В portable-версии пользовательские скрипты и назначения клавиш снова загружаются, если путь к распакованной папке содержит кириллицу.
- Для Windows 7 SP1 три пакетных конвертера собраны с совместимым набором WinAPI; EPUB-конвертер больше не требует `CreateFile2`. Запуск Batch EXE двойным щелчком показывает подсказку вместо мгновенно закрывающегося окна.
- При ошибке загрузки пользовательского JavaScript-скрипта FBE показывает имя и путь файла, строку, столбец, контекст, исходное сообщение и HRESULT; сведения можно скопировать.
- Исправлены отображение неразрывного пробела и повреждённые русские/украинские подписи, подсказки и имена команд в настройках.
- Все страницы окна настроек используют единый шрифт и размер.

### Что требуется проверить

- Переходы между «Телом», «Описанием» и «Кодом» с обычными абзацами, заголовками, аннотациями, стихами, цитатами и изображениями.
- Portable-режим из путей с кириллицей, пробелами и длинными именами.
- Batch-конвертеры на Windows 7 SP1 и Windows 10/11.
