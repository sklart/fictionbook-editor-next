# EPUB: сжатие при экспорте

Экспортёр записывает `mimetype` первым и без сжатия, а текстовые файлы — методом raw Deflate через уже используемую zlib. PNG, JPEG, GIF и WebP сохраняются методом Store. Поток сжатия использует буфер 64 КиБ; исходные ограничения встроенного ZIP32 и существующая транзакционная замена файла сохранены. Код Sigil не копировался: изучен подход его упаковщика к порядку `mimetype` и выбору метода сжатия.

Для Win32 используется обычный подготовленный проектом `build\zlib\install\<Configuration>`. При отдельной сборке проекта ExportEPUB для x64 zlib предварительно собирается командой `tools\build\build-zlib.ps1 -Platform x64 -Configuration Release` (или `Debug`); она размещается отдельно от Win32.

На синтетической FB2 размером 13 201 344 байта, на одном компьютере, три последовательных запуска штатного `ExportEPUBBatch` в EPUB 3 дали медиану 1,293 с и пиковый наблюдаемый working set 86 585 344 байта до изменения; после изменения — 1,333 с и 86 380 544 байта. Размер EPUB уменьшился с 13 207 751 до 93 146 байт. Текст намеренно повторяющийся, поэтому этот результат не является оценкой для произвольной книги. Содержимое всех распакованных записей и CRC совпали; автоматически формируемое время `dcterms:modified` перед сравнением нормализовано.

Для небольшой книги `fb2-metadata-cyrillic-smoke.fb2` EPUB 3 уменьшился с 8 959 до 4 420 байт. Для EPUB 2 извлечённые записи совпали побайтно. В обоих версиях выполнена проверка структуры первой записи и фактической распаковки. Повреждение целевого файла при неудачной перезаписи проверяется существующим тестом экспортёра.
