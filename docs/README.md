## Отчёты, история и сопровождение документации

[Сводный статус проверок](testing/verification-status.md) отделяет результаты конкретных прогонов от текущих обещаний. [Рабочие отчёты](testing/reports/README.md) относятся к ещё не закрытой приёмке. [Архив](archive/README.md) сохраняет исследования причин дефектов, измерения и воспроизводимые исторические проверки.

[Правила сопровождения](maintenance/policy.md) определяют порядок обновления и удаления документов. [Контрольные входы тестов](maintenance/protected-evidence.md) сохраняют исходные байты и хеши. Старые пути и якоря не поддерживаются; внутренняя навигация ведёт непосредственно к действующим инструкциям или полезным историческим исследованиям.

**Порядок источников:** код, схемы и исполняемые build/test-сценарии определяют реализованный контракт; документация объясняет его; опубликованный GitHub Release остаётся источником пользовательского описания конкретного выпуска. Исторический PASS подтверждает только указанную в отчёте сборку и окружение.
