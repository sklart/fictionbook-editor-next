База: `5f77d048fedf05755d99469edb2304d33f6b9b77`. Отчёт дополняет [предыдущую приёмку](community-defects-3.0.10-closure.md), а не заменяет её. Общий статус: **BLOCKED** до безопасного исправления Split/Undo; полный release gate и ручная проверка не должны считаться пройденными по частичным результатам.

## CONFIRMED FIXED

- При сохранении пустых параграфов сохраняются ID. Импорт EPUB сохраняет прямые переносы строк и не создаёт повторяющийся заголовок книги. Зафиксированы 71 fidelity-тест, XSD и 214 ID после Save/Reopen предоставленной книги; коммерческая книга не опубликована. Классификация 94 текстовых различий, 19 дополнительных блоков и трёх подписей NCX, а также проверка 73 вложенных связей находятся в предыдущем отчёте и [обезличенной классификации](evidence/community-3010-epub-94.json).
- Тест `arrow-space` имел гонку: при диагностически задержанной доставке стрелки на 250 мс проверка по истечении фиксированных 80 мс фиксировала `keyboard=0` до получения клавиши. После изменения тест ждёт исходный фокус, доставку стрелки и смену фокуса, затем оба события пробела и закрытие диалога. Контрольный сценарий с той же задержкой прошёл, как и остальные проверки диалогов. Данные [до и после](evidence/community-3010-keyboard-delayed.json) и об [обычных прогонах](evidence/community-3010-keyboard-observations.json). Это доказывает конкретную гонку теста; причина прежнего отдельного отказа без диагностики не установлена. Обработка клавиатуры production не изменялась.

## FAIL / BLOCKED

Split/Undo — подтверждённый дефект целостности документа: после Undo остаются дублированные раздел и ID, последующие Undo исходный DOM не восстанавливают. Из 16 сценариев ранее не прошли `split-section-middle`, `split-wrapper-success`, `split-section-multi-paragraph-selection`. Их результаты TSV и структурные trace приложены к [техническому заключению](split-undo-closure-decision.md). Тест и gate не ослаблены; глобальный Undo не изменён. Будущее исправление требует отдельного решения по [ТЗ](split-undo-safe-fix-spec.md).

На итоговой сборке повторный `split-section-middle`: FAIL, `before_equals_undo=0`, `after_equals_redo=1`. Стандартный `verify-release.ps1 -Configuration Release`: **FAIL** до этапа Split. Тест `test-editor-background-runtime.ps1` завершил функциональные проверки PASS, но его проверка изоляции обнаружила изменение `%LOCALAPPDATA%\FBE Next` между снимками. Во время прогона присутствовали и другие экземпляры FBE, а файлы пользовательского профиля изменялись; непосредственная причина изменения не установлена. Gate не обходился. Локальный журнал: `build/evidence/stabilization-verify-release.log`. В его составе тест тематических диалогов и UI defects light/ru-RU прошли. FullValidation: **NOT RUN** из-за обязательных блокеров.

Итоговая сборка Release Win32 выполнена штатным скриптом с v143 / VC Tools 14.44 и строгими предупреждениями; provenance создан, отслеживаемые Scintilla/Lexilla не изменены. Адресный тест диалогов прошёл на ней в обычном режиме и с контролируемой задержкой; 28 сценариев реальной вставки прошли.

## INCONCLUSIVE

Случай `word` однажды завершился с `0xC0000005`; Windows Application Error 1000 указал `ntdll.dll` 10.0.26100.9711, offset `0x000827cd`, PID 32936, путь к изолированному FBE. В архиве WER сохранился отчёт, но временный WER dump недоступен; штатный dump имеет нулевую длину и текстовый crash report отсутствует. Обработчик сначала создаёт файл и вызывает `MiniDumpWriteDump`, а текст пишет после его завершения: имеющихся данных недостаточно, чтобы установить, почему запись прервалась, получить стек или определить первоначальное состояние MSHTML/OLE и буфера. По имени системного модуля нельзя установить первопричину. Защитные механизмы не отключались, production-код Clipboard не изменялся.
