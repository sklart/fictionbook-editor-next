FBE NEXT BACKGROUNDS
====================

Подготовленный набор фоновых текстур для FictionBook Editor Next.

Состав:
- 14 текстур PNG;
- размер каждой: 1024 x 1024;
- RGB, без альфа-канала;
- края подготовлены для бесшовного повторения;
- имена файлов только ASCII — меньше проблем с file:// и старыми HTML-движками;
- backgrounds.json содержит fallback-названия, ключи локализации, fallback-цвет и рекомендуемый цвет текста.

Рекомендуемый режим применения в FBE Next:
  background-repeat: repeat;
  background-attachment: fixed;

Для светлых текстур рекомендуемый цвет текста: #202020.
Для тёмных текстур рекомендуемый цвет текста: #E8E8E8.

Что было сделано:
- приведён единый размер 1024 x 1024;
- выровнено низкочастотное освещение/градиенты;
- приглушены слишком активные перепады фактуры;
- сохранены оттенок и характер исходных изображений;
- подготовлено бесшовное повторение;
- оптимизирован PNG.

Исходные изображения в архив не включены.
