# Save Sections As Separate Documents

Утилита `SaveSectionsAsSeparateDocuments.hta` разделяет одну FB2-книгу на
самостоятельные FB2-документы: по отмеченным разделам или по всем разделам
верхнего уровня. Это Windows HTA для FictionBook Editor Next.

## Запуск

Откройте HTA в Windows, выберите файл `.fb2`, затем выберите разделы и режим
извлечения автора и названия. Для вариантов «автор + название» и «название +
автор» каждый выбранный заголовок должен иметь как минимум два абзаца.

По умолчанию файлы сохраняются рядом с исходным документом. Папку можно выбрать
в форме; имя задаётся шаблоном `{number}_{author}_{title}`. Поддерживаются
маркеры `{number}`, `{author}` и `{title}`, а при необходимости можно включить
Unicode-имена вместо транслитерации. Поле «Предпросмотр» показывает итоговый
путь для первого создаваемого файла.

## Что сохраняется

Для каждого результата утилита сохраняет выбранный раздел и его вложенность,
нужные примечания/комментарии, используемые изображения вместе с `binary` и
создаёт новый `document-info/id`. Можно извлекать автора и название из
заголовка либо оставить исходных авторов. Ошибка одного файла не останавливает
обработку остальных разделов; итоговое окно показывает счётчики.

## XML и безопасность

Требуется **MSXML 6.0**. Fallback на MSXML 3.0 отсутствует: сохранение и
проверка результата используют единый набор возможностей MSXML 6.0. DTD,
внешние ресурсы и XML-
валидация при разборе отключены. При ошибке разбора показываются файл, код,
причина, строка, позиция и проблемный фрагмент.

Каждый результат записывается во временный файл, затем повторно открывается и
проверяется как FB2. Только после успешной проверки временный файл переименовывается
в итоговый. Ошибка одного файла не должна использоваться как основание считать
остальные результаты созданными. Имена очищаются от недопустимых Windows
символов, управляющих символов, конечных точек/пробелов и reserved names
(`CON`, `AUX`, `COM1`, `LPT1`).

## Отличия от исходной версии Sclex

Исходный сценарий создан Sclex; авторство сохранено в HTA и списке участников.
Версия FBE Next сохраняет интерфейс и привычный процесс, но добавляет:

* обязательный MSXML 6.0 вместо переключения между версиями;
* временную запись, повторное чтение и schema-проверку FB2 перед заменой
  целевого файла, с откатом при ошибке;
* независимую обработку названия и автора: нераспознанная часть авторской
  строки не удаляет исходные `<author>`;
* XPath-обработку `xlink:href`, сохранение используемых `binary` и очистку
  ненужных notes/comments;
* безопасные имена файлов и preview;
* автоматические проверки legacy JScript и безопасной записи.
