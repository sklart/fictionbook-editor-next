# Save Sections As Separate Documents

Утилита `SaveSectionsAsSeparateDocuments.hta` разделяет FB2-книгу на отдельные
документы по выбранным разделам или по всем разделам верхнего уровня.

## Запуск

Откройте HTA в Windows, выберите файл `.fb2`, затем выберите разделы и режим
извлечения автора и названия. Для вариантов «автор + название» и «название +
автор» каждый выбранный заголовок должен иметь как минимум два абзаца.

По умолчанию файлы сохраняются рядом с исходным документом. Папку можно выбрать
в форме; имя задаётся шаблоном `{number}_{author}_{title}`. Поддерживаются
маркеры `{number}`, `{author}` и `{title}`, а при необходимости можно включить
Unicode-имена вместо транслитерации.

## XML и безопасность

Утилита автоматически использует MSXML 6.0, а при его отсутствии — MSXML 3.0;
выбранная версия показана после открытия файла. DTD, внешние ресурсы и XML-
валидация при разборе отключены. При ошибке разбора показываются файл, код,
причина, строка, позиция и проблемный фрагмент.

Каждый результат записывается во временный файл, затем повторно открывается и
проверяется как FB2. Только после успешной проверки временный файл переименовывается
в итоговый. Ошибка одного файла не должна использоваться как основание считать
остальные результаты созданными.
