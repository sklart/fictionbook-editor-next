# Справка по регулярным выражениям — Код

## Движок

Поиск в Source использует **Scintilla** с `SCFIND_REGEXP` и `SCFIND_CXX11REGEX`. Это не PCRE2.

## Отличия от Дизайна

Дизайн использует PCRE2-16, UTF/UCP, advanced PCRE2 и грамматику замен FBE. Source использует C++11-regex Scintilla и `SCI_REPLACETARGETRE`.

## Построчный поиск

Поиск в Source выполняется **построчно** через `MatchOnLines`. Regex не сопоставляет текст через границы строк. `\r\n`, `\n`, `\x0D` и `\x0A` не включают межстрочный поиск в этом пути.

## Символы, классы и якоря

Доступны буквальные символы, экранирование `\`, классы `[abc]`, `[^abc]`, диапазоны `[a-z]`, `\d`, `\D`, `\s`, `\S`, `\w`, `\W`. `^` и `$` — границы строк, `\b` и `\B` — границы слов. Работают группы `(…)`, альтернатива `|`, квантификаторы `*`, `+`, `?`, `{n,m}` и обратная ссылка `\1`.

## Замена

Замена выполняется `SCI_REPLACETARGETRE`. Делайте Source-замены простыми и сначала проверяйте на небольшом фрагменте.

## Неподдерживаемые PCRE2-конструкции

Нет UCP, `\p{...}`, lookbehind, `\K`, `\G`, branch reset, PCRE2 verbs, подпрограмм PCRE2 и форматирования замен FBE Design.

## Примеры FB2/XML

| Задача | Regex Source |
| --- | --- |
| Пустой `<p>` | `<p>[ \t]*</p>` |
| Два empty-line на одной строке Source | `<empty-line/>[ \t]*<empty-line/>` |
| Пустые метаданные | `<(book-title|first-name|last-name)>[ \t]*</\1>` |
| Пустое форматирование | `<(strong|emphasis)>[ \t]*</\1>` |
| Вложенное форматирование | `<(strong|emphasis)>[^<]*<(strong|emphasis)>` |
| Legacy HTML-тег | `</?(font|span|div)\b[^>]*>` |
| Тег в верхнем регистре | `</?[A-Z][A-Z0-9:-]*\b[^>]*>` |
| `&nbsp;` | `&nbsp;` |
| Числовая entity | `&#[0-9]+;|&#x[0-9A-Fa-f]+;` |
| Пустой id | `\bid=""` |
| Внешний URL | `(https?|file):[^" ]+` |
| Пустой href | `href=""` |
| `#undefined` | `(href|src)="#undefined"` |
| Bookmark | `href="#[^"]+"` |
| `_ftnref` / `_ednref` | `_ftnref|_ednref` |
| Ссылка на сноску | `<a(?=[^>]*type="note")[^>]*>` |
| Возможный marker сноски | `\[[0-9]+\]` |
| Неопределённая картинка | `<image[^>]+href="#undefined"` |
| windows-1251 | `encoding="windows-1251"` |

Шаблон двух `<empty-line/>` специально разрешает только пробелы и табуляции: он не ищет через строки Source.

## Частые ошибки и ограничения

Не вставляйте PCRE2-синтаксис в Source и не считайте `\s*` межстрочным. Перед заменой проверяйте XML, особенно id, ссылки и маркеры сносок. Многострочный Source regex здесь не реализован: он затронет `^`/`$`, Replace All, производительность и текущие Scintilla-regressions.
## Minimal pattern
```xml
<empty-line/>[ \t]*<empty-line/>
```
