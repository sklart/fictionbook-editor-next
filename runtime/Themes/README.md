# Поставляемые темы XML-подсветки

FBE Next читает UTF-8 JSON-файлы с расширением `.fbetheme` из этой папки
при запуске. Каждый файл имеет `formatVersion: 1` и полный набор из 23
логических цветовых ролей. Файлы с расширением `.json` намеренно не загружаются.

В основной поставке находятся 21 внешняя палитра. Вместе с вариантами
«Как в системе», FBE Light, FBE Dark и «Историческая FBE» список содержит
25 вариантов выбора. Высококонтрастные экспериментальные схемы не показываются;
старые настройки автоматически переводятся в FBE Light или FBE Dark.
