# Проверенные источники

Публичные источники проверены 4 августа 2026 года. Форматы полученных локальных датасетов НКРЯ проверены 2 сентября 2026 года.

## Imperius/ru-classic

- Назначение: чистый корпус русской классической литературы XIX — начала XX века.
- Объём по карточке: 866 МБ очищенного текста, 61 автор.
- Лицензия сборки: CC0-1.0.
- Ограничение: источник собран с `lib.ru`; возможны редкие OCR-артефакты. Для орфографии нельзя использовать вариант с нормализацией `ё → е`.

## maxzt/RuHeritage-Corpus

- Назначение: классика из Русской Викитеки с полями `author`, `title`, `text`, `source_url`.
- Объём по карточке: около 9292 записей.
- Лицензия сборки: CC BY 4.0.
- Ограничение: карточка применяет критерий общественного достояния США. Для публикации полного производного корпуса вне тестовой машины требуется отдельная проверка спорных авторов и редакций.

## Русская Викитека

- Назначение: русские переводы зарубежной литературы.
- Условия: текст страниц доступен по CC BY-SA; отдельные произведения могут находиться в общественном достоянии.
- Механизм: загрузчик сохраняет полную ссылку, `revision_id`, дату ревизии и категории страницы.

## PleIAs/Russian-PD

- Назначение: стресс-корпус дореволюционных изданий и OCR.
- Объём по карточке: 8525 наименований, около 995 млн слов.
- Статус: Public Domain по карточке набора.
- Ограничение: автоматический OCR; не использовать как эталон правильного написания.

## ai-forever/spellcheck_benchmark

- Назначение: реальные пары русских предложений с ошибками и исправлениями.
- Состав: RUSpellRU, MultidomainGold, MedSpellchecker и GitHubTypoCorpusRu.
- Лицензия: MIT.
- Использование: оценка обнаружения опечаток и позиций правильного варианта в подсказках.

## Офлайновые датасеты Национального корпуса русского языка

- Назначение: независимая локальная проверка словарей Hunspell на вручную размеченной и диахронической русской лексике.
- Источник описания: https://ruscorpora.ru/page/corpora-datasets/
- Получение: непосредственно у НКРЯ по подписанным пользователем лицензионным соглашениям; ссылки скачивания и сами архивы в репозитории не сохраняются.
- `rnc_morphological_standard`: XHTML в Windows-1251 с `<w><ana lex="..." gr="..."></ana>словоформа</w>`; используется отдельный строгий класс `strict_clean`.
- `rnc_syntagrus`: UTF-8 `.tgt` с `LEMMA` и `FEAT`; используется как независимый размеченный тест покрытия.
- `rnc_diachronic_*`: UTF-8 `.txt.gz`, одно предложение на строку; читаются потоково и оценивают покрытие по историческим срезам, а не нормативность.
- `rnc_multilingual_ru`: из локального параллельного JSON извлекается только русская сторона `ru`.
- Ограничение распространения: исходные данные, подготовленные token-level JSONL, CSV с контекстами и FB2-review не должны публиковаться или коммититься без отдельной проверки условий подписанного соглашения. В публичных материалах предпочтительна агрегированная статистика.
